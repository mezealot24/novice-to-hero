# 💥 Critical Strike — กติกาที่โค้ดทำจริง (v94, 2026-11-07)

> สถานะ: **เอกสารอธิบายของที่มีอยู่แล้ว** (ไม่ได้เปลี่ยนบาลานซ์) · ไล่จาก `BattleScene.strike()` / `roll()`, `meta.ts` (`heroStats`, `applyBase`), `perks.ts`
> ตัวเลขใน "ค่าสูงสุดโดยประมาณ" เป็นการประเมินคร่าวๆ ยังไม่ได้วัดในเกม

## TL;DR (so what)

- มี **2 กองโอกาสคริ**: `crit` (กายภาพ) กับ `spellCrit` (เวท) · **ดาเมจคริ `critMul` ใช้ตัวเดียวกัน**
- ของ / perk / tree / ทาเลนต์ ที่ให้ "โอกาสคริ" บวกเข้า **ทั้งสองกอง** · **LUK บวกเข้า `crit` กองเดียว** (Mage ได้ `spellCrit` เพิ่ม 1% ต่อ 6 LUK)
- on-hit / หอก / แสงรุ่งอรุณ ทั้งหมดเป็นเวท → ใช้ `spellCrit` · ตีธรรมดา / ทุบ Ult / สกิลกายภาพ ใช้ `crit`
- ไม่เจอ cap ของ `crit` และ `critMul` ฝั่งฮีโร่

## 1. โอกาสคริ

| กอง | ใช้กับ | แหล่งที่เข้า |
|---|---|---|
| `crit` | ตีธรรมดา · ทุบ Ult · สกิลกายภาพ (`magic = false`) | LUK (1% ต่อ 3 LUK) · ของ · การ์ด · tree · ทาเลนต์ · perk · เซ็ตคริ (+20%) · relic |
| `spellCrit` | หอกแสง · สายฟ้า / ไฟ / น้ำแข็ง · Holy Light · โบนัสแสงรุ่งอรุณ · สกิลเวท (`magic = true`) | ทุกอย่างที่ให้ `crit` (บวกให้อัตโนมัติ) · mod `spellCrit` ตรงๆ (ของ "เวทคริ") · Mage: LUK 1% ต่อ 6 LUK |

- ทอยต่อ **ฮิต** (หอก 1 เล่มยิง 3 ตัว = 3 ทอย)
- เพิ่มชั่วคราวเฉพาะกายภาพ: ตาเหยี่ยว (Skill 2), `critAdd` (Swordsman จังหวะดาบ: คริตามสแต็ก), ร่างคลั่ง (Berserker)
- `forceCrit` (คริแน่): Rogue stab, Knight ตอบโต้ ★, Swordsman ★ พันดาบ, ★ อรุณพิทักษ์
- บวกโอกาสคริ +100% ชั่วคราว: สถานะ 777 (ดาวทั้งสาม) และ mutator "คริหรือศูนย์" (`crit: 1` ผ่าน `applyMod` เข้าทั้งสองกอง)
- ฮีลคริไม่ได้

## 2. ดาเมจคริ

- `critMul` เริ่มที่ **1.4** (ตัวคูณรวม ไม่ใช่ +140%) · ทุกแหล่งเป็น **การบวก**: perk จุดตาย +0.6 / +1.0, relic, unique, taint, tree
- ตอนคริ ใช้ค่า**สูงสุด**ของช่วงดาเมจ (ไม่สุ่มต่ำ)
- ★ อรุณพิทักษ์: บวก `critMul` +0.5 ชั่วคราวระหว่างโบนัสแสงรุ่งอรุณ → 1.9 ที่ค่าเริ่มต้น
- โบนัสเฉพาะ: ตาเหยี่ยว ★ (`hawkCritDmg`), Zen หลัง Ult (`zenCritDmg`)

## 3. คริ vs มอนสเตอร์

| กติกา | รายละเอียด |
|---|---|
| ข้าม P.DEF | กายภาพที่คริไม่โดนหัก P.DEF · เวทคริยังโดน M.DEF |
| ข้าม MISS | คริไม่ต้องผ่านการทอย Hit/Flee · แต่ lucky dodge / fixedFlee ของมอนยังทำงาน |
| มอนมี `statDef.critDR` (ดัน 6+) | ลดดาเมจคริ แต่ไม่ต่ำกว่าตีปกติ |
| venomqueen (Toxic Skin) | bonus คริเหลือครึ่งเดียว · −5% ดาเมจ |

## 4. มอนคริใส่ฮีโร่

- มอนที่มี `def.crit` ทอยเอง ดาเมจ x**1.6** (`BATTLE.monCritMul`) ลดตาม `critDR` ของฮีโร่ แต่ไม่ต่ำกว่าตีปกติ
- คริของมอนหลบไม่ได้ (lucky dodge / โล่ยังทำงาน)
- `critDR` ฮีโร่: LUK x/(x+400) + ของ · cap **50%**

## 5. perk ในดันที่เกี่ยวกับคริ (perks.ts)

| perk | Lv1 | Lv2 (+) | หมายเหตุ |
|---|---|---|---|
| 🎯 ตาเหยี่ยว | โอกาสคริ +15% | +25% (รวม) | Lv2 บวกส่วนต่างให้ครบ |
| 💥 จุดตาย | ดาเมจคริ +60% | +100% (รวม) | |

## 6. ค่าสูงสุดโดยประมาณ (ยังไม่วัด)

- โอกาสคริปลายเกม: LUK ~100 (33%) + perk (25–36%) + เซ็ตคริ 20% + relic (15–20%) + ของ/การ์ด/tree อีกหลายสิบ % → **เกิน 100% ได้** ส่วนที่เกินใช้ไม่ได้ (ไม่แปลงเป็นอย่างอื่น)
- `critMul`: 1.4 + perk 1.0 + unique 0.8 + relic 0.6 + taint 0.4 + อื่นๆ → ปลายเกมอยู่ราว x4–5 ถ้าเก็บครบ
- **ยังไม่ตัดสินใจ**: ต้องมี cap ไหม · ควรดูจาก data ผู้เล่นจริง ไม่ใช่ดูแต่บอท

## 7. UI (v94)

- หน้า Stat: แถว `คริ / ต้านทาน` → **`คริ กาย / เวท`** · ต้านทานย้ายไปแถว `Hit / Flee / ต้านทาน` (จำนวนแถวเท่าเดิม แผงไม่ล้น)
- ร้าน/กระเป๋า (`compareLine`): ถ้าของเพิ่มทั้งสองกองเท่ากันแสดง `คริ +x%` เหมือนเดิม · ถ้าเปลี่ยนไม่เท่ากันแยก `คริ กาย` / `เวทคริ`
- Stat info (LUK): เพิ่มบรรทัดบอกว่าเวทคริมาจากของ / perk / tree เท่านั้น (Mage ได้จาก LUK)

## 8. ที่ยังไม่ได้ทำ / ต้องตัดสินใจ

- **LUK → `spellCrit` สำหรับ Priest**: ตอนนี้ Priest เห็นคริ 5.3% แต่หอก / แสงรุ่งอรุณ (ก่อนมี ★) ได้ 0% · ถ้าเปลี่ยนเป็นการเปลี่ยนบาลานซ์ ต้องดูผลสาย Priest ก่อน
- cap ของ `crit` / `critMul` (ดูหัวข้อ 6)
