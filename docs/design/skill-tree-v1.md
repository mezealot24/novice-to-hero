# Skill Tree v1 (ร่าง) — อาชีพละ 2 สาย

> สถานะ: ร่างให้คิวรีวิว ยังไม่แตะโค้ด · 2026-11-03 · ต่อจาก `squishy-class-counterplay.md` และ `research/capybara-go-research.md`

## TL;DR (so what)

- **อาชีพละ 2 สาย สายละ 4 โหนด** (เวทมี 3 สาย ตามธาตุของ ult) · โหนดสุดท้าย = **capstone เลือกได้สายเดียว** → build ของแต่ละคนต่างกันจริง
- **ใช้แต้มสกิลกองเดียวกับสกิลออโต้/ult** และ **อัปไม่ครบทุกอย่าง** ต้องเลือก
- **โหนดส่วนใหญ่เป็น stat ที่มีในเกมแล้ว** (counter, combo, lifesteal, crit shield, mana shield, พิษ, ไฟ) → ทำเร็ว
- ทุกอาชีพมี **"วิธีรอด" คนละแบบ** ตามที่คุยกันไว้ · โจรได้ "หลบแล้วฮีล" แก้จุดอ่อนจากบอทเทสต์

## 1. กติกากลาง

| เรื่อง | กติกา |
|---|---|
| แต้ม | 1 แต้ม / Job Lv (Job Lv 1→40 = 39 แต้ม) · กองเดียวกับสกิลออโต้/ult (อัป 2 ตัวนั้นเต็มใช้ 18) |
| โหนด | โหนด 1–3 อัปได้ 3 เลเวล · โหนด 4 (capstone) มี 1 เลเวล |
| ปลดล็อก | โหนดที่ N ต้องลงแต้มในสายนั้นแล้ว (N−1)×2 แต้ม · capstone ต้องลงในสายนั้น 6 แต้ม |
| Capstone | **ได้แค่ 1 อันต่ออาชีพ** (เลือกสาย = เลือกตัวตน) |
| รีเซ็ต | ฟรี เหมือนรีเซ็ต stat (ให้ลองผิดลองถูกได้ ไม่ลงโทษคนสมาธิสั้น) |
| งบรวม | สกิล 18 + tree 2 สาย × 10 = 38 ≈ 39 แต้ม → ปลาย Job Lv เกือบเต็ม แต่ต้องเลือก capstone อันเดียว |

> Certificate (Base Lv 10/20/30/40) ยังไม่ใช้ใน v1 · ไอเดียต่อยอด: ช่อง Cert ใส่ **โหนดของอาชีพอื่นที่เคยเล่น** ได้ 1 โหนด/ช่อง (แบบ Eden Eternal)

## 3. ความเสี่ยง (SA note)

- **Counter + combo ซ้อนกันอาจ snowball** โดยเฉพาะนักดาบสาย A (บอทเห็นนักดาบสวน ~20 ครั้ง/รอบแล้ว) → cap counter 60% คงไว้ และสวนพายุ 0.5x ไม่ใช่ 0.8x
- **โหนด "ตาย" แล้วกระจาย** (ไฟ/พิษ) แรงมากในเวฟฝูง แต่ไม่ช่วยตอนบอส → ตั้งใจให้เป็น trade-off กับสายอื่น
- **อย่าให้ tree ทำให้ดัน 2 ง่ายเกิน**: ตัวเลข tree วัดที่ Job Lv ~15 (≈ 14 แต้ม) ไม่ใช่ Lv 40
- UI ต้องไม่รก: แสดงเป็น **2 คอลัมน์ 4 แถว** ในแท็บสกิลเดิม ไม่ใช่กราฟเส้นโยง

## 4. แผนทำ (MVP, bite-size)

1. **ข้อมูล**: `TREES` ใน `data/jobs.ts` (โหนด = id, สาย, ระดับ, max, `mod(lv)`) · เซฟ `jobTree: Record<nodeId, lv>` ใน save
2. **UI**: แท็บสกิลแสดง 2 คอลัมน์ ปุ่ม + / ล็อก / capstone ★ · ปุ่มรีเซ็ตฟรี
3. **รอบแรกทำเฉพาะโหนด ✅** (สาย stat ล้วน) + capstone อย่างละอาชีพ → เล่นได้ทันที
4. **รอบสองทำโหนด 🛠️** ทีละอาชีพ เริ่มจาก **โจร** (หลบแล้วฮีล) เพราะอ่อนสุด
5. บอทเทสต์ที่ Job Lv 15 ลง tree สุ่ม · เป้า: ทุกอาชีพชนะดัน 2 ราว 8–11/12

## อัปเดต 2026-11-03: Talent ใช้แต้มแยก (คิวตอบ "ใช้แต้มแยก")
