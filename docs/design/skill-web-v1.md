## TL;DR (so what)

- **ตอนนี้มี 2 หน้า แต่ใช้แต้มกองเดียวกัน** ทำให้งง
  - หน้า "สกิล" = อัปเลเวลสกิลออโต้กับ ult (Lv 1–10 เลเวลละ +10% แรง) ตัวเลขขึ้นอย่างเดียว ไม่เปลี่ยนวิธีเล่น
  - หน้า "ต้นสกิล" = 2–3 สาย สายละ 4 โหนด เป็น passive (สถานะ/เอฟเฟกต์ เช่น โล่หนาม, ล็อกเป้า)
- **ข้อเสนอ: รวมเป็นหน้าเดียวชื่อ "สกิล"** เป็นใยโหนดแบบ RO/PoE มีโหนดกลางแล้วแตกออกเป็น 3 สาย ตามช่องสกิล 3 ช่องของทุกอาชีพ
  - **ทักษะ 1** = สกิลออโต้เดิม (ใช้ resource อัตโนมัติ)
  - **ทักษะ 2** = ช่องใหม่ ต้นสายเป็นทางแยก **เลือก 1 จาก 3 active** (Mana Shield ของเวทอยู่ตรงนี้)
  - **Ult** = ท่าไม้ตายเดิม (กดเอง, คูลดาวน์)
- "อัปเลเวลสกิล" เดิม → กลายเป็น **โหนดแรงขึ้น** ที่อยู่ในสายของสกิลนั้นเอง ลงแต้มที่ไหนก็เห็นเลยว่าสกิลไหนเก่งขึ้น
- **แต้มกองเดียว** (1 แต้มต่อ Job Lv เหมือนเดิม ~39 แต้มตลอดเกม) แต่ทั้งใยมีโหนดรวม ~55 แต้ม → **ลงได้ราว 2 สายเต็ม ต้องเลือก build**
- **ทาเลนต์ (⭐) แยกไว้เหมือนเดิม** ทาเลนต์เป็นตัวเปลี่ยนสไตล์ที่ปลดตาม Job Lv และใช้แต้มคนละกอง ถ้ารวมเข้าใยด้วยจะแน่นเกิน หนูแนะนำให้แยกไว้ค่ะ
- **ทักษะ 2 ร่ายเองอัตโนมัติ** เมื่อคูลดาวน์ครบและ resource พอ ไม่ต้องกดเพิ่ม เพราะเกมเป็นแบบ auto (ปุ่มกดเองมีแค่ ult เหมือนเดิม)

## 1. หน้าตาใย (ทุกอาชีพใช้รูปเดียวกัน)

```
                 [Ult ★cap]
                     |
              [ult+] [ult mod]
                     |
               (Ult: ท่าไม้ตาย)
              /              \
   [stat]  ── ( ◆ แก่นอาชีพ ◆ ) ──  [stat]
         /                         \
 (ทักษะ 1)                     {ทักษะ 2: เลือก 1/3}
   |                            /     |      \
 [S1+][S1 mod]               [A]     [B]     [C]
   |                          |       |       |
 [S1 ★cap]                 [A+]    [B+]    [C+]
                              |       |       |
                            [A★]    [B★]    [C★]
```

- **◆ แก่นอาชีพ** (ฟรี): passive ประจำอาชีพที่มีอยู่แล้ว เช่น โจร "เงาบาง"
- **โหนด stat** (วงเล็ก ระหว่างสาย): +HP / +M.ATK / +ฟื้น resource ใช้เป็นทางเชื่อมข้ามสายแบบ PoE ลงได้โดยไม่ต้องลงสายนั้นลึก
- **กฎปลดล็อก (แบบ RO)**: โหนดจะลงได้ต่อเมื่อโหนดก่อนหน้าในเส้นมีอย่างน้อย 1 แต้ม · ★capstone ต้องลงสายนั้นครบ 6 แต้ม · **★ ได้ 2 ดวงต่ออาชีพ** (เดิมได้ 1 ดวง เพราะตอนนี้มี 3 สาย)
- **ทักษะ 2**: เลือกได้ 1 จาก 3 (A/B/C) และเปลี่ยนได้ฟรีในเมือง (รีเซ็ตใยฟรีเหมือนเดิม) สาขาย่อยของตัวที่ไม่ได้เลือกจะเป็นสีเทา
- โหนด "S1+ / ult+" = แรงขึ้น +10%/lv (สูงสุด 5) **มาแทนเลเวลสกิล 1–10 เดิม**

## 3. ย้ายของเดิมเข้าใย (ไม่ทิ้งงานเก่า)

- โหนดต้นสกิลเดิม 2–3 สาย/อาชีพ → แจกเข้าสาย ทักษะ 1 / Ult / stat ตามว่าไปเสริมสกิลไหน (เช่น เวท ⚡ สายฟ้า → สาย Ult เพราะเสริม ult สายฟ้า, ❄️ เกราะน้ำแข็ง → Ult, 🔥 ลูกไฟติดเชื้อ → ทักษะ 1)
- สายธาตุของเวท: ★ ของ ult แยกตามธาตุเหมือนเดิม (ฟ้าลิขิต / เถ้าลุกลาม / ผลึกแตก) เลือกได้ดวงเดียว
- **เซฟเก่า**: ตอนเปิดเวอร์ชันใหม่ครั้งแรก คืนแต้มสกิล + แต้มต้นสกิลทั้งหมด แล้วโชว์ป้าย "ระบบสกิลใหม่! ลงแต้มใหม่ได้ฟรี" ไม่ต้องแปลง id ทีละตัว
- การ์ด/พรระหว่างรัน (Lightning Bolt ฯลฯ) **ไม่เปลี่ยน**
