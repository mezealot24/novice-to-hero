# ดันเจี้ยน 8 · 🌋 แกนภูเขาไฟ (v80)

## TL;DR (so what)

- Lv60-70 · tier 8 · ปลดล็อกหลังเคลียร์ D7 · มอนสเตตัสแบบ D6 (`statMonster`)
- ทดสอบ: **อึด + ฮีลทั้งที่ติดไฟ** (ไฟบนเรา = ฮีลลด 40%) · **ศพระเบิด** · **สะท้อนดาเมจ** (ตีมั่ว = เจ็บเอง)
- ค่าทุก tier ≈ D6 × 1.35-1.5 (ข้ามสองดัน) → D7 ที่ Lv50-60 จะอยู่ตรงกลางพอดี
- ไฟล์: `src/data/dungeons/d8.ts` · `src/gfx/tex/d8.ts` · ไม่แตะไฟล์กลาง
- ⚠️ **ยังไม่ได้วัดด้วยบอท (รอคิวอนุญาต)**

## ธีม / ทดสอบอะไร

| กลไก | มาจากใคร | ผู้เล่นต้องทำอะไร |
|---|---|---|
| 🔥 ไฟบนเรา (ฮีล -40%) | สไลม์ · ซาลาแมนเดอร์ · นักเวท · อิฟรีต · บอส | `debuffRes` / ล้างสถานะ / ฮีลเยอะกว่าปกติ |
| 💥 ตายแล้วระเบิด | สไลม์แมกมา (x2) · ค้างคาวถ่านลุก (x1.5) | อย่าฆ่าตอนเลือดน้อย · โล่/หลบช่วย |
| 🪞 สะท้อน | โกเลม 10% · บอสเฟส 2 8% | สายตีแรงทีเดียวเจ็บเอง · DoT ปลอดภัย |
| 🔮 กลืนดาเมจ | อิฟรีต 25% → 35% | ใช้ไฟ/พิษ (DoT ไม่ถูกกลืน) · เตรียมโล่ตอนชาร์จ |
| 💢 บัฟสะสม | วัลคราน (warcry self ไม่หมดอายุ) | จบเร็ว · ไฟตัดดูดเลือดมัน |
