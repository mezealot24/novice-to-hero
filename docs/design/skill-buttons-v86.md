# v86 ปุ่มสกิลแบบ MOBA (ROV)

ย้าย HUD มุมขวาล่างเป็นกลุ่มปุ่มวงกลม: Ult ใหญ่ + ทักษะ 1/2/3 เรียงเป็นโค้งรอบ Ult
กฎล้วน ๆ อยู่ที่ `src/battle/skill-hud.ts` (test: `tests/skill-hud.test.ts`), วาดใน `BattleScene` (`buildSkillHud` / `refreshSkillHud`)

## Layout (canvas 960x576, FIT)

```
                       [3]            3 = ทักษะ 3 (มีอาชีพ 2) 270 deg
                  [2]                 2 = ทักษะ 2 (เลือกแล้ว) 225 deg
 [โหมด] [1]      ( ULT )              1 = ทักษะ 1 180 deg, Ult ศูนย์กลาง (W-64, H-64)
```

| ปุ่ม | รัศมี | touch |
|------|-------|-------|
| Ult | 48 | 96px |
| ทักษะ 1/2/3 | 28 | 56px |

- วงโค้งรัศมี 88 จากศูนย์ Ult, ช่องว่างระหว่างปุ่ม >= 6px (test เช็คให้)
- ปุ่ม `⚡ อัตโนมัติ / 🖐️ กดเอง` อยู่ซ้ายของทักษะ 1
- Novice ใช้ปุ่มทุบยาวแบบเดิม (มีแค่ ult)
- ทักษะ 1 ซ่อนถ้าอาชีพไม่มี resource, ทักษะ 2 ซ่อนถ้ายังไม่เลือก, ทักษะ 3 ซ่อนถ้าไม่มีอาชีพ 2

## สถานะของปุ่ม

| สถานะ | แสดง |
|-------|------|
| คูลดาวน์ | วงมืดแบบ radial sweep (สัดส่วน cd เหลือ/cd เต็ม) + เลขเทิร์นที่เหลือตรงกลาง |
| Resource ไม่พอ | ปุ่มหม่น + เลขต้นทุนแดง |
| พร้อม | วงเรืองแสงกะพริบ |
| จอง | วงทองสองชั้น + ป้าย "จอง" |
| ร่ายสำเร็จ | ปุ่มเด้ง (scale) + แฟลชขาว |
| Mage ร่าย ult | วงเวทหมุนรอบปุ่ม Ult |
| ถูกใบ้ / Monk ลูกพลังไม่ถึง | ปุ่มหม่น (ไม่ใช่เลขแดง) |

ต้นทุนแสดงในวงกลมด้านล่าง: 💧 Mana / 🔥 Rage / ⚡ Energy (Monk ทักษะ 3 แสดง 🔵 ลูกพลัง n/ต้องการ)
วาดใหม่เฉพาะตอน signature เปลี่ยน (ไม่วาด Graphics ทุกเฟรม)

## กฎการจอง

| โหมด | พฤติกรรม |
|------|----------|
| ⚡ ออโต้ (ค่าเริ่มต้น) | ทักษะ 1/2/3 ออกเองเหมือนเดิม, แตะ = ข้อความเตือนสั้น ๆ, Ult ทำงานเหมือนเดิม (แตะ = ยกเลิก/จอง) |
| 🖐️ กดเอง | ทักษะ 1/2/3 และ Ult ออกเมื่อ "จอง" เท่านั้น, แตะ = สลับจอง |

- ทักษะที่จองไว้ออกในเทิร์นฮีโร่ถัดไปที่ cd/resource พอ แล้วเลิกจองเอง
- ทักษะ 1 ที่ไม่ได้จอง = ตีธรรมดา (เก็บ Mana ไว้ให้ ult). Cleric ตีทุบทุกเทิร์นเหมือนเดิม, ทักษะ 1 ออกเฉพาะที่จอง
- ลำดับในเทิร์นเหมือนเดิม: ทักษะ 2 / 3 ต้นเทิร์น -> Ult -> ทักษะ 1 / ตีธรรมดา
- จบ wave: ล้างการจองทักษะ 1/2/3 (Ult คงพฤติกรรมเดิม)
- สลับกลับเป็นออโต้: ล้างการจองทั้งหมด
- โหมดเก็บที่ `save.autoUlt` ('auto' | 'manual') ตัวเดียวกับเดิม และสลับได้จากเมนูพักเกม

## Hotkey (เฉพาะโหมดกดเอง)

`1` `2` `3` = จองทักษะ 1/2/3, `4` = จอง Ult, `Space` = Ult (เหมือนเดิม ทุกโหมด)
ไม่ทำงานตอนมี overlay เลือกพร/อีเวนต์/พักเกม (ปุ่มเลข 1-4 ตรงนั้นเลือกการ์ด)
