# Skill admin engine v1 — แท็บ "⚔️ สกิลอาชีพ" (รอบ 1)

> Q ขอ 2026-11-07: engine เสริมปรับสกิลในหน้า admin — ทักษะ 1 / 2 / 3 / Ult ของทุกคลาส
> **รอบ 1 = โครงเครื่อง + 5 อาชีพพื้นฐาน (ทักษะ 1 · 2 · Ult)** · ทักษะ 3 + อาชีพขั้น 2 = รอบ 2
> ต่อยอดจาก live-config เดิม (`design/live-tuning.md`): draft → ทดสอบ (`?cfg=draft`) → publish → rollback ใช้ flow เดิมทั้งหมด

## So what
- เปิด admin → แท็บ **⚔️ สกิลอาชีพ** → เลือกคลาส → เห็น 3 คอลัมน์: ทักษะ 1 | ทักษะ 2 (ทั้ง 3 ท่า) | Ult
- ทุกคอลัมน์มีช่อง **"คริได้ไหม"** ช่องแรกสุด · **ค่าเริ่มต้น = 1 (คริได้ทุกท่าเหมือนเดิม)** → ยังไม่มีบาลานซ์เปลี่ยนจนกว่า Q จะตั้ง 0 เอง
- ตัวเลขในคำอธิบายสกิลบนจอเกมยังเป็นค่า build (ข้อความถูกสร้างตอน import) แต่ค่าที่คำนวณจริงเปลี่ยนตามที่ตั้ง

## สวิตช์คริ (`skills crit.<class>.<slot>`)
| สถานะ | ผล |
|---|---|
| 1 (default) | ฮิตของท่านั้นทอยคริได้เหมือนเดิม |
| 0 | ฮิต **ของท่านั้นเอง** (src skill / ult / other) ไม่ทอยคริ |
| ไม่ถูกสวิตช์คุม | คริตายตัว (`forceCrit` เช่น ★ พันดาบ) · ดาเมจ on-hit (zap / fire / ice / spear / light / poison) |

- slot: `s1` ทักษะ 1 · `s2` ทักษะ 2 (ใช้ร่วมกันทั้ง 3 ท่า) · `ult`
- อาชีพขั้น 2 ใช้สวิตช์ของคลาสแม่ไปก่อน (รอบ 2 แยก slot ของตัวเอง + `s3`)
- กฎ "on-hit ไม่คริ" ที่ Q ต้องการ **ยังไม่ทำ** — เป็นอีกก้อน (เปลี่ยนบาลานซ์จริง) ตอนนี้ on-hit คริตามกฎเดิม
- ถ้าอยากได้ "สกิลไม่คริโดยปริยาย ยกเว้นบางท่า": ตั้ง 0 ทุกช่อง แล้วเปิด 1 เฉพาะท่าที่ตั้งใจ (เช่น ทุบ Ult นักบวช) ผ่าน draft → ทดสอบ → publish ได้เลย

## ที่เปลี่ยนใน code
- `src/data/skill-registry.ts` (ใหม่) — แผนที่ class × slot → ช่อง + `SKILL_CRIT` + `canRollCrit()`; ตาราง `skills` สร้าง whitelist จากไฟล์นี้
- `src/data/tunables.ts` — เพิ่มตาราง `skills` (ไม่ต้อง bump `CONFIG_SCHEMA`: path เดิมความหมายเดิม)
- `src/data/skill-math.ts` — สูตร Skill 2 ที่เป็น `ค่าฐาน + ต่อเลเวล × lv` ย้ายเป็นตัวเลข `S2P.<key>.base|per` (ผลลัพธ์ default เท่าเดิมเป๊ะ มีเทสต์กัน)
- `src/data/patch.ts` — `rebuildDerived()` sync ค่า Mana ที่ `jobs.ts` คัดลอกตอน import (ดูล่าง)
- `src/scenes/BattleScene.ts` — `asSkill(fn, src, slot)` จำ slot · `strike()` เช็ก `critAllowed()` (ไม่เปลี่ยนลำดับการสุ่ม → ผลเหมือนเดิมเมื่อสวิตช์ = 1)
- `src/admin/main.ts` + `admin.html` — แท็บใหม่
- `tests/skill-registry.test.ts` — 7 เทสต์

## บั๊กเก่าที่เจอระหว่างทำ (แก้แล้ว)
`kit cleric.ultMana`, `SWORD_MANA.auto`, `SWORD_MANA.ult` เคยแก้แล้ว **ไม่มีผลในเกม** เพราะ `JOBS` คัดลอกค่าไปตอน import แต่โค้ดร่ายสกิลอ่านจาก `JOBS`
→ `rebuildDerived()` คัดลอกซ้ำหลัง apply/revert ทุกครั้ง · ถ้า release ที่ publish ไว้แล้วมี `kit.cleric.ultMana` ค่าไม่ใช่ 30 ช่องนั้นจะเริ่มมีผลจริง (ตรวจ live ก่อน publish ครั้งหน้า)

## เพิ่มตัวเลขใหม่เข้าแท็บ (สำหรับรอบหน้า)
1. ยืนยันก่อนว่าเกมอ่านค่านั้น **ตอนรัน** (ไม่ใช่ copy ตอน import)
2. เพิ่ม `sk(path, label, def)` (หรือ `kit(path, label)` ถ้าอยู่ใน `kit` แล้ว) ใน `SKILL_LAYOUT` ของคลาส/ท่านั้น
3. `npm test skill-registry` — เทสต์จะเช็กว่า path อยู่ใน whitelist, อ่านเป็นตัวเลข, default อยู่ในช่วง, และมีแถวในหน้า admin
