# 🗡️ โจร — Skill Tree + Talent (สเปกเต็ม)

> สถานะ: **ลงเกมแล้ว v15** (2026-11-03) · เดิม: รอคิวรีวิว · 2026-11-03 · ต่อจาก `skill-tree-v1.md` (คิวอนุมัติแล้ว) · ใช้ framework จากเธรด "Rethink gameplay for squishy classes" (`data/trees/thief.ts`)

## TL;DR (so what)

- **ทาเลนต์ใช้ Talent Point แยกกอง** (1 TP / 5 Job Lv, rank 1–2) อัปเดต 2026-11-03
- **ตัวตนโจร = "ยิ่งหลบ ยิ่งแรง"** หลบได้แล้วได้ของ (ฮีล / Energy / สวนกลับ) · สายพิษไว้ล้มบอสช้าๆ
- **เจอต้นเหตุที่โจรอ่อนจริงๆ แล้วค่ะ**: สูตร hit ของมอนมี **พื้น 80%** → Flee ต่อให้สูงแค่ไหน โจรหลบได้ **ไม่เกิน ~20%** (+ lucky ~3%) และท่าทุบของบอสหลบด้วย Flee ไม่ได้เลย → "สายหลบ" ตันตั้งแต่เกิด
- แก้ด้วย **passive ประจำอาชีพ "เงาบาง"**: พื้น hit ของมอนที่ตีโจร ลดจาก 80% → 70% (tree/ทาเลนต์ลดต่อได้ถึง 60%) · กระทบแค่โจร ไม่แตะอาชีพอื่น
- Tree 2 สาย × 4 โหนด ตาม v1 เดิม (เติมตัวเลข) + **ทาเลนต์ 4 แถว × 3 ตัวเลือก, rank 1–2** (Job Lv 5/10/20/30)
- บอทเทสต์ล่าสุด (ดัน 2, 10 รอบ, Job Lv 1): **ของพื้นฐาน 4/10 · ของโจร 10/10** → ปัญหาอยู่ที่ "โจรตัวเปล่า" ตายที่บอส (บอสเหลือ 266–462 HP) · เป้าหลัง tree: ของพื้นฐาน **7–9/10** ไม่ทำให้ของโจรง่ายเกิน

## 1. Diagnosis (หลักฐาน)

| เรื่อง | ค่าปัจจุบัน | ผล |
|---|---|---|
| `hitChance()` | `clamp(0.80 + (Hit−Flee)×1%, 0.80, 0.98)` | มอน Hit 26–30 · โจร Flee ~24 → หลบ 16–18% · Flee เกิน Hit ของมอน = **เสียเปล่า** |
| ท่าทุบบอส | `monHit 999` | Flee ไร้ผล เหลือแค่ lucky (cap 25%) / เงาพริ้ว / BREAK |
| พิษ | cap 12 stack × 2 ดาเมจ = 24/เทิร์นมอน | บอส 1350 HP → พิษช่วยแค่ ~15% ของงาน |
| dodgeHeal | มีแต่ในของ (cap 8%) | ตัวเปล่าไม่มี sustain เลย → อธิบายผล 4/10 vs 10/10 ได้ตรง |

## 2. Passive ประจำอาชีพ (ไม่ใช้แต้ม)

- 🌫️ **เงาบาง** — มอนตีโจรโดนอย่างน้อย **70%** แทน 80% (`fleeFloor: 0.10`, เพดานรวม 0.20 = พื้น 60%)
- เหตุผล: ทำให้ Flee ทุกแต้มยังมีค่า · ไม่แตะท่าทุบบอส (ยังต้องใช้ ult/BREAK)

## 3. Skill Tree

กติกาตาม v1: โหนด 1–3 อัป 3 lv · capstone 1 lv · โหนดที่ N เปิดเมื่อลงสายนั้น (N−1)×2 แต้ม · capstone ต้องลง 6 · เลือก capstone ได้อันเดียว · รีเซ็ตฟรี

### สาย A: ☠️ พิษ — "ล้มบอสช้าแต่ชัวร์"
| # | โหนด | ต่อ lv | เต็ม | key |
|---|---|---|---|---|
| 1 | 🧪 เคลือบพิษ | พิษ +1 stack/hit | +3 | `poison` ✅ |
| 2 | 💀 พิษเข้มข้น | ดาเมจพิษ +1/stack | +3 | `poisonDmg` ✅ |
| 3 | 🫙 พิษสะสม | เพดานพิษ +3 stack | 12 → 21 | `poisonCap` ✅ (framework) |
| ★ | 💥 **ระเบิดพิษ** | มอนตาย → stack พิษ 50% กระจายไปทุกตัวที่เหลือ | — | `poisonSpread` ✅ (framework) |

เต็มสาย: 21 stack × 5 = **105/เทิร์นมอน** ใส่บอส (จาก 24) → บอสดัน 2 ตายเร็วขึ้น ~3–4 เทิร์น

### สาย B: 🌑 เงา — "หลบแล้วฟื้น หลบแล้วสวน"
| # | โหนด | ต่อ lv | เต็ม | key |
|---|---|---|---|---|
| 1 | 👣 ย่องเบา | Flee +4 · พื้น hit −2% | Flee +12 · −6% | `flee`, `fleeFloor` 🛠️ |
| 2 | 🌙 หายใจในเงา | หลบได้ → ฟื้น 2% HP สูงสุด | 6% | `dodgeHeal` ✅ |
| 3 | 🔪 มีดคู่ | คอมโบ +5% · คริ +3% | +15% · +9% | `combo`, `crit` ✅ |
| ★ | 👤 **เงาสวน** | หลบได้ทุกครั้ง → แทงสวน 0.8x (ติดพิษได้) | — | `dodgeStrike` ✅ (framework) |

- cap `dodgeHeal` สำหรับโจรขยับ 8% → **10%** (tree 6% + ของ 6.5% จะไม่ล้นจนอมตะ)
- เต็มสายที่ Job Lv ~15: หลบ ~30% + lucky ~3% → หลบ 1 ใน 3 ครั้ง ได้ฟื้น 6% ทุกครั้ง

## 4. Talent (Talent Point แยกกอง)

กติกา (ตามที่คิวตอบในเธรดนักดาบ): **1 TP ต่อ 5 Job Lv** (Lv40 = 8 TP) · แถวเปิดที่ Job Lv 5/10/20/30 · **เลือกได้แถวละ 1 ตัว** · แต่ละตัวมี **rank 1–2** (1 TP/rank) · รีเซ็ตฟรีในเมือง
→ 8 TP = 4 แถว × rank 2 พอดีตอนตัน · ระหว่างทางต้องเลือกว่าจะ "เปิดแถวใหม่" หรือ "อัปตัวเดิมเป็น rank 2"

| แถว (Job Lv) | ตัวเลือก (rank 1 → rank 2) | key |
|---|---|---|
| **1 (5) ตั้งตัว** | 🐈 **ฝีเท้าแมว** Flee +8 · หลบโชคดี +3% → Flee +14 · หลบโชคดี +5% | `flee`, `luckyDodge` ✅ |
| | 💨 **ม่านควัน** เริ่มทุกเวฟ หลบครั้งแรกแน่นอน 1 ครั้ง → 2 ครั้ง | `waveDodge` 🛠️ |
| | 🩸 **หนังหนา** HP สูงสุด +40 → +80 | `maxHp` ✅ |
| **2 (10) จังหวะ** | ⚡ **ขโมยจังหวะ** หลบได้ → Energy +15 → +25 | `dodgeEnergy` 🛠️ |
| | 🎯 **จุดบอด** คริ +6% → +10% | `crit` ✅ |
| | 🧪 **ซองพิษ** แทงพิษใช้ Energy −10 → −16 | `autoCostCut` ✅ |
| **3 (20) ท่าไม้ตาย** | 👥 **เงาซ้อน** เงาพริ้วหลบ +1 ครั้ง (2→3) → +2 ครั้ง (2→4) | `ultDodge` 🛠️ |
| | 🔪 **พายุมีด** เงาพริ้วแทง 4 → 6 ที → 4 → 7 ที | `ultHits` 🛠️ |
| | ☠️ **มีดอาบพิษ** เงาพริ้วแต่ละทีติดพิษ +2 → +3 stack | `ultPoison` 🛠️ |
| **4 (30) ล้มบอส** | 🧫 **กัดกร่อน** มอนที่พิษ ≥ 10 stack รับดาเมจ +15% → +25% | `poisonAmp` 🛠️ |
| | 🗡️ **นักฆ่า** ดาเมจคริ +30% → +50% | `critMul` ✅ |
| | 🌫️ **ร่างเงา** พื้น hit −5% → −8% (ยังติด cap รวม 0.20 = พื้น 60%) | `fleeFloor` 🛠️ |

- rank 2 ตั้งให้ได้ **~+60–70% ของ rank 1** (ไม่ใช่ x2) → การเปิดแถวใหม่คุ้มกว่าเล็กน้อยเสมอ คนไม่รู้จะเลือกอะไรก็ไม่พลาด
- แต่ละแถวมี **สายหลบ / สายตีแรง / สายพิษ** อย่างละตัว → เข้ากับ tree ที่ลงไว้ได้ทุกแบบ
- ตอนบอทเทสต์ที่ Job Lv 15 = **3 TP** (แถว 1–2 เปิด + rank 2 ได้ 1 ตัว)

## 5. Build ตัวอย่าง (ให้เห็นว่าเลือกแล้วต่างกันจริง)

- **🌑 เงาอมตะ** (สาย B ★ เงาสวน): ฝีเท้าแมว · ขโมยจังหวะ · เงาซ้อน · ร่างเงา → หลบเยอะ ฟื้นเรื่อยๆ สวนกลับรัว
- **☠️ หมอพิษ** (สาย A ★ ระเบิดพิษ): ม่านควัน · ซองพิษ · มีดอาบพิษ · กัดกร่อน → ฝูงตายเป็นลูกโซ่ บอสละลายช้าๆ
- **🔪 มีดคู่คริ** (สาย B ไม่ถึง ★ + สาย A 1–2): หนังหนา · จุดบอด · พายุมีด · นักฆ่า → burst

## 6. งานโค้ด (Phase 2 · เฉพาะโจร)

ใหม่ 🛠️ ทั้งหมด = key ใน `Stats` + อ่านใน `BattleScene`:
1. `fleeFloor` → `hitChance(hit, flee, floor = 0.8)` รับพื้นเป็นพารามิเตอร์ (default เดิม อาชีพอื่นไม่เปลี่ยน) · ใช้เฉพาะ `hurtHero` ตอนโจรโดนตี · cap 0.20
2. `dodgeEnergy`, `waveDodge` → ใน `dodged()` / ต้นเวฟ
3. `ultDodge`, `ultHits`, `ultPoison` → `case 'thief'` ของ ult
4. `poisonAmp` → ใน `damageMon` ถ้า `m.poison >= 10`
5. ข้อมูลทั้งหมดใน `data/trees/thief.ts` · passive `fleeFloor: 0.1` ใน `JOBS.thief.mod`
6. บอทเทสต์ดัน 2 ที่ Job Lv 15 (tree สุ่ม + ทาเลนต์สุ่ม 3 TP) ของพื้นฐาน vs ของโจร · เป้า 7–9/10 และ 10/10 ต้องไม่ "ชนะโดย HP เต็ม" ทุกรอบ

## 7. ผลจากกติกาคริใหม่ (คิวสั่ง 2026-11-03: คริไม่ให้โล่แล้ว · ดาเมจคริแบบ RO)

- คริแบบ RO = **ไม่สน DEF และ Flee ของเป้า** · ตัวคูณคงที่ ~1.4x + โบนัสดาเมจคริ
- **ฝั่งโจรได้ประโยชน์**: LUK ให้คริ → คริไม่ MISS และทะลุ DEF บอส (25) → สาย "มีดคู่คริ" กับทาเลนต์ 🗡️ นักฆ่า (`critMul` +30%/+50% บวกเข้าโบนัสดาเมจคริ) แรงขึ้นเองโดยไม่ต้องแก้ตัวเลข
- **ฝั่งโจรเสียประโยชน์ (ถ้ามอนคริได้)**: คริของมอนข้าม Flee และข้าม "เงาบาง" ด้วย
  - ตาม RO จริง **Perfect Dodge (หลบโชคดีจาก LUK) ยังหลบคริได้** → หนูเสนอให้คงลำดับเดิม: `เงาพริ้ว/ม่านควัน → หลบโชคดี → (คริมอน ข้าม Flee) → Flee`
  - เงาพริ้ว (ult) และ 💨 ม่านควัน เป็น "หลบแน่นอน" ต้องหลบคริได้ด้วย ไม่งั้นท่าไม้ตายโจรไม่มีความหมาย
  - ตอนนี้มอนยังไม่มีค่าคริในโค้ด → ถ้าจะเพิ่มคริให้มอน แนะนำให้ต่ำ (≤5%) และบอสไม่คริตอนทุบ
- โหนดสาย B ไม่ต้องแก้ · ถ้าบอทเห็นว่าคริมอนกินโจรเยอะ ค่อยเพิ่ม 🐈 ฝีเท้าแมว rank 2 หลบโชคดี +5% → +6%

## 8. ความเสี่ยง (SA note)

- **หลบ + ฟื้น + สวน ซ้อนกันอาจอมตะ** ในเวฟฝูง → คุมด้วย cap: พื้น hit ต่ำสุด 60%, dodgeHeal 10%, lucky 25% · ท่าทุบบอสยังหลบด้วย Flee ไม่ได้
- **ระเบิดพิษ** แรงในเวฟ แต่ไม่ช่วยบอส → ชดเชยด้วยทาเลนต์ "กัดกร่อน" (เลือกแลกกับร่างเงา/นักฆ่า)
- โหนด id เป็น save data ห้ามเปลี่ยนชื่อหลังปล่อย
