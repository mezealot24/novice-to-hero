# สายตัวบางหลังแยกอาชีพ: ตัวเลขหรือเกมเพลย์? (design assessment v1)

> สถานะ: **คิวเลือกตัวเลือก A แล้ว ทำในเกมแล้ว (v7)** · วันที่ 2026-11-03 · อ้างอิง: `BattleScene.ts`, `data/jobs.ts`, `stat-system-v1.md`, `dungeon-2-and-events.md`

## TL;DR (so what)

- **คำตอบ: เป็นช่องโหว่ของดีไซน์ ไม่ใช่แค่ตัวเลข** แต่ไม่ต้องรื้อระบบเทิร์น side-scroll แค่เติม "ชั้น counterplay" ที่หายไป
- ปัญหาจริง: เกมมีแกนป้องกันแค่แกนเดียวคือ **HP / โล่ / ฮีล** ซึ่งนักดาบกับนักบวชมี ส่วนนักธนูกับจอมเวท **ไม่มีเครื่องมือตอบโต้ท่าใหญ่ของบอสเลย**
- แนะนำ **ตัวเลือก A: เพิ่ม "Break" (ขัดจังหวะบอส) + ปรับ ult ให้ทุกอาชีพมีคำตอบตอนบอสชาร์จ** งานเล็ก ~1 วัน ไม่เพิ่มระบบใหม่ฝั่ง UI
- ระบบใหญ่ (แถวหน้า-หลัง, ปาร์ตี้) ยังไม่คุ้ม เพราะมีฮีโร่ตัวเดียว ตำแหน่งไม่มีความหมาย

## 1. หลักฐานจากโค้ด: ทำไมตัวบางถึงแพ้บอส

| สิ่งที่พบ | ที่มา | ผล |
|---|---|---|
| ท่ากระโจนของบอสเป็น **ดาเมจเวท หลบไม่ได้** (`hurtHero(..., magic=true, hit=999)`) | `BattleScene.slam()` | Flee/AGI ของสายเร็วไร้ค่าในจังหวะที่อันตรายที่สุด · P.DEF ก็ไม่ช่วย · มีแค่ WIS (M.DEF) กับ LUK ที่ช่วย ซึ่งธนู/เวทไม่ได้อัป |
| กระโจน = `(26+8) × 0.55 × 1.6 ≈ 30` + มึน (เสีย gauge 45) | `slam()` + `BATTLE.slamStun` | โดนทีเดียว ~25–30% HP ของตัวบาง แล้วยังเสียเทิร์นถัดไปอีก = โดนสองเด้ง |
| คำใบ้ในเกม: "เก็บท่าไม้ตายไว้ใช้ตอนบอสชาร์จ" | `banner()` ห้องบอส | **ใช้ได้แค่ 3 อาชีพ**: นักดาบ (โล่), นักบวช (โล่+ฮีล), โจร (หลบ 2 ครั้ง) · ธนู (ฝนธนู) กับเวท (อุกกาบาต) เป็นดาเมจล้วน กดตอนชาร์จก็ไม่รอด |
| "ระยะไกล" ไม่มีผลเชิงป้องกัน | `basicAttack()` | ธนูยืนจุดเดียวกับนักดาบ โดนตีเท่ากัน ได้แค่ P.ATK จาก DEX · fantasy "ยิงจากไกล = ปลอดภัย" ไม่มีจริงในกลไก |
| Hit floor 80% | `hitChance()` | Flee ลดโอกาสโดนได้สูงสุดแค่ 18% แม้อัป AGI สุด · แกน "หลบ" จึงอ่อนโดยสเปก |
| บอส HP < 50% เรียกหมาป่าเงา 2 ตัว (hit 26, speed 14) | `monTurn()` | ตัวบางที่ไม่มี AoE ดี (ธนู) โดนรุม 3 ตัวพร้อมกระโจน · เวทมี AoE เลยรอดดีกว่าธนูนิดหน่อย ตรงกับผลบอท (เวท 1–2/3, ธนู 1/4) |

สรุป: นักดาบ/นักบวชชนะไม่ใช่เพราะเลขเยอะกว่า แต่เพราะ **มีปุ่มกดตอบโต้บอสได้** ส่วนตัวบางไม่มี นี่คือช่องโหว่ดีไซน์ ถ้าแก้ด้วยการเพิ่ม HP อย่างเดียว ก็แค่เปลี่ยนตัวบางเป็น "นักดาบที่ยิงไกล" ซึ่งทำให้อาชีพไม่ต่างกัน

## 2. ตัวเลือก

### A. เติมชั้น counterplay (แนะนำ, MVP)

หลักคิด: ในเกมเทิร์นที่ auto-fight จุดที่ผู้เล่น "เล่น" จริงมีจุดเดียวคือ **ตอนบอสชาร์จ** ทุกอาชีพต้องมีคำตอบในจังหวะนั้น แต่คำตอบไม่เหมือนกัน

1. **Break (ขัดจังหวะ)**: ตอนบอสอยู่ในสถานะชาร์จ ถ้าโดนดาเมจรวม ≥ `breakPct` ของ HP สูงสุด (เสนอ 6–8%, บอสจ่าฝูง ≈ 80–110) ท่ากระโจนถูกยกเลิก และบอส "เซ" (gauge -30)
   - การป้องกันของ glass cannon = ความแรง ตรงตามคอนเซ็ปต์อาชีพ
   - เวท: อุกกาบาต 2.4× ทะลุแน่ · ธนู: ฝนธนู 3 ระลอก ทะลุถ้าแต้มพอ · นักดาบ: Break ยาก แต่มีโล่ · = แต่ละอาชีพเล่นคนละแบบ
   - ทำแค่: field `breakPct` ใน MonsterDef + ตัวนับดาเมจระหว่างชาร์จใน `damageMon()` + แถบ "⚡ BREAK" ใต้ HP บอส (~30 บรรทัด)
2. **ให้ ult ตัวบางมีกลิ่นป้องกันนิดเดียว** (คง identity ดาเมจ)
   - ธนู "ฝนธนู" → "ถอยยิง": ได้ **หลบแน่นอน 1 ครั้ง** + ยิง 3 ระลอกเหมือนเดิม (kiting แบบไม่ต้องมีระบบตำแหน่ง)
   - เวท "อุกกาบาต" → เพิ่ม **ผลัก gauge มอนทุกตัว -40** (ชะลอเทิร์นศัตรู = control) 
3. **ท่าใหญ่ของบอสต้องมี "ชนิด"** : จ่าฝูงกระโจน = **กายภาพ** (P.DEF ลด, Flee หลบไม่ได้แต่ LUCKY ได้) · บอสเวทในอนาคตค่อยเป็นเวท → stat ที่อัปมีความหมายตอนบอสจริงๆ ตามที่ตั้งใจไว้ในสเปก
4. **หมาป่าที่ถูกเรียกเริ่มด้วย gauge 0** (ตอนนี้สุ่ม 0–40) ให้ผู้เล่นมี 1 เทิร์นตั้งตัว
5. ตัวเลขเล็กน้อย: ธนู/เวท `mod.maxHp +15` ตอนเปลี่ยนอาชีพ (ยังบางกว่านักดาบ +40 มาก)

เป้าหลังแก้ (บอทสุ่ม, เพิ่งเปลี่ยนอาชีพ): ทุกอาชีพ 2–3/4 · ไม่มีอาชีพไหน 4/4 หรือ 1/4 · นักดาบอาจลงมาที่ 3/4 ถือว่าโอเค

### B. ปรับตัวเลขอย่างเดียว (เร็วที่สุด แต่ไม่แก้ราก)

- HP ตัวบาง +30, ลดดาเมจกระโจน 1.6 → 1.3, หมาป่าเรียกมา 2 → 1
- ได้ 65% → ~80% ภายในชั่วโมงเดียว แต่ความต่างระหว่างอาชีพจะเหลือแค่สีกับแอนิเมชัน และบอสตัวต่อไปจะเจอปัญหาเดิมอีก
- เหมาะถ้าคิวอยากไปทำ M5 ก่อน แล้วค่อยกลับมา

### C. ระบบใหญ่ (ยังไม่แนะนำ)

| ระบบ | ทำไมยัง | เมื่อไหร่ถึงคุ้ม |
|---|---|---|
| แถวหน้า-หลัง / ระยะ | มีฮีโร่ตัวเดียว ไม่มีใครยืนบังให้ "แถวหลัง" จึงเท่ากับ "โดนช้าลง 1 เทิร์น" ทำแบบข้อ A.2/A.4 ได้ผลเดียวกันถูกกว่า | เมื่อมีปาร์ตี้/เพื่อนร่วมทาง |
| ปาร์ตี้ / companion | ต้องทำ AI, UI, การ์ดของเพื่อน, ตีบาลานซ์ใหม่หมด = milestone ใหม่ (M6+) ไม่ใช่ patch | หลัง PvP ผี (M5) ถ้าอยากขยายเกม |
| สเตตัสใส่ฮีโร่ (พิษ/ช้า) จากมอน | ทำให้ตัวบางยิ่งยาก ควรทำหลังมี counterplay ก่อน | หลัง A |

## 3. ลำดับทำถ้าเลือก A

1. `game-data.ts`: `breakPct` ให้ `alpha` (และ `king` ด้วยเพื่อความสม่ำเสมอ) · `slam()` อ่านชนิดดาเมจจาก def (`slamMagic?: boolean`)
2. `BattleScene.ts`: ตัวนับ `chargeDmg` รีเซ็ตตอนเริ่มชาร์จ · ใน `damageMon()` ถ้า `m.charging && chargeDmg >= hp*breakPct` → ยกเลิก, floatText "⚡ BREAK!", gauge -30
3. `ultimate()`: ธนู +1 dodgeCharge · เวท ลด gauge มอนทุกตัว 40
4. `jobs.ts`: HP ธนู/เวท +15 · desc ult ใหม่
5. `addMon()` ตอน summon: gauge 0
6. บอทเทสต์ 5 อาชีพ × 4 รอบ เทียบกับตารางใน `dungeon-2-and-events.md` ข้อ 4 · แก้ `breakPct` จนทุกอาชีพอยู่ 2–3/4

## 4. สิ่งที่ทำจริง (2026-11-03)

- **Break**: จ่าฝูงเงา `breakPct 0.09` (≈122 ดาเมจระหว่างชาร์จ), ราชาเจลล็อป 0.08 · แถบฟ้าใต้ HP บอส · break แล้วบอสเสีย gauge 30
- ตอนบอสเริ่มชาร์จ ฮีโร่ได้ **1 เทิร์นตอบโต้แน่นอน** (heroGauge ≥ 100)
- ธนู: ult ได้หลบแน่นอน 1 ครั้ง · **คริแล้วได้โล่ 10% ของดาเมจ** (`critShield`) · HP +15
- เวท: ult ผลัก gauge ศัตรู -40 + บาเรีย 2x M.ATK · ~~Mana Shield~~ (ตัดใน v21 คิวสั่ง: สกิลเวทใช้ Mana แทน) · HP +15
- กระโจนจ่าฝูงเป็นกายภาพ (`slamMagic` ไม่ได้ตั้ง) · ราชาเจลล็อปยังเป็นเวท
- หมาป่าที่บอสเรียกเริ่ม gauge 0
- การ์ดทั่วไป **ขนนกฟีนิกซ์**: ล้มครั้งแรกลุกใหม่ 30% HP · ได้ 1 ใบ/รอบ ไม่คูณ x2 ตอนเป็นตำนาน
