# ดัน 4–5 สายโหด · บึงพิษมรกต + บัลลังก์อเวจี (v1, 2026-11-03)

**สรุปสั้น:** เพิ่ม 2 ดันที่ "โหดเพราะกลไก" ไม่ใช่แค่ HP หนา: มอนมีสกิลของตัวเอง (ฮีล โล่ โห่ร้อง สาป ปลุกศพ ระเบิด สะท้อน) ใส่สถานะผิดปกติให้เรา, mini boss 1-1 ตัวใหม่ 4 ตัว, บอสใหญ่หลายเฟส, สกิลขั้นสูงสุดใหม่ 4 อัน, ของร้านใหม่ 2 ชิ้นไว้กันสถานะ

## 0. รีวิวของเดิม (ก่อนเพิ่ม)
- bot (Lv 10 + ของดัน 2) ชนะดัน 3 ได้ 28/30 รอบ · มอนดัน 1–3 ทุกตัว "แค่ตี" ต่างกันแค่ HP/DEF/Flee/เวท → ยากขึ้นด้วยตัวเลขอย่างเดียว ไม่มีอะไรให้คิด
- มีแต่บอสที่มีกลไก (ชาร์จ/BREAK, เรียกลูกน้อง) และ mini boss ดัน 3
- จอมเวทแรงเกิน: ล้มบอสดัน 3 ใน 5–11 เทิร์น (ลิมิต 40) · นักบวช/นักดาบใช้ 25–32 เทิร์น เกือบชนลิมิตทุกรอบ
- ฝั่งเรามีของเล่นเยอะมาก (โล่ ดูดเลือด สวน คอมโบ พิษ ไฟ) แต่ศัตรูแทบไม่มีอะไรมาตอบโต้ → ดัน 4–5 เลยเน้น "ให้ศัตรูมีของเล่นบ้าง"

## 1. ระบบใหม่ (ใช้ได้กับดันต่อๆ ไป แค่เพิ่มข้อมูล)
ข้อมูลอยู่ที่ `game/src/data/game-data.ts` (MonsterDef: `skills`, `onHit`, `slamFx`, `reflect`, `deathBlast`, `phases`) · ลอจิกที่ `BattleScene` (`useSkill`, `applyFx`, `enterPhase`, `dotHurt`, `reflectHurt`)

**สกิลมอน** (ใช้แทนการตีในเทิร์นที่ N ถ้ามีประโยชน์ เช่น ฮีลเฉพาะตอนมีพวกเลือดต่ำกว่า 80%)
| สกิล | ทำอะไร |
|---|---|
| heal | ฮีลพวกที่เลือดน้อยสุด (ไฟ/ไฟโลกันตร์ตัดฮีลได้) |
| shield | ให้โล่ทุกตัว (ไม่ซ้อน) โล่ซับดาเมจก่อน HP |
| warcry | พวกทั้งหมดตีแรงขึ้น N เทิร์น (บารัค: ใส่ตัวเองแบบสะสม) |
| curse | ใส่สถานะใส่เรา ไม่พลาด |
| revive | ปลุกพวกที่ตายในด่านนี้ 1 ตัว ที่ 50% HP (ตัวละครั้งเดียว) |
| summon | เรียกลูกน้องลงช่องว่าง |

**สถานะผิดปกติใส่เรา** (โชว์ใต้หลอด HP · จบเมื่อจบการต่อสู้)
| ไอคอน | สถานะ | ผล |
|---|---|---|
| ☠️ | พิษ (stack สูงสุด 8) | ต้นเทิร์นเรา เสีย 1% max HP ต่อ stack แล้วลด 1 stack |
| 🔥 | ไฟลุก | ต้นเทิร์นเสีย 3% max HP · ฮีลเข้าเรา -40% |
| 💔 | อ่อนแรง | ดาเมจเรา -25% |
| 🛡️💥 | เกราะแตก | P.DEF / M.DEF นับครึ่งเดียว |
| 🤐 | ใบ้ | ใช้ท่าไม้ตาย/ทุบไม่ได้ (ยังจองไว้ได้) |
| ❄️ | แช่แข็ง | เสียเกจเทิร์น (ต้านทาน/tenacity ลดได้) |

ทางแก้: ค่าใหม่ **กันสถานะผิดปกติ** (`debuffRes`, โอกาสปัดทิ้ง) จากของร้าน · สกิลขั้นสูงสุด ✨ กายบริสุทธิ์ (กันทุกอย่าง) · โล่ซับดาเมจพิษ/ไฟได้ · ขนนกฟีนิกซ์ยังช่วยชีวิตได้

**อื่นๆ:** สะท้อนดาเมจ (🪞 ตีโดนแล้วเราเจ็บเป็นเวท · DoT ไม่สะท้อน) · ระเบิดตอนตาย (💥 เวท หลบด้วย Flee/LUCKY/โล่ได้) · โล่มอน · บอสหลายเฟส (ข้าม % HP แล้ว: ฮีล/โล่/เรียกลูกน้อง/ล้างไฟพิษตัวเอง/เร็วขึ้น/แรงขึ้น/ชาร์จถี่ขึ้น/เปลี่ยนสถานะที่ใส่)

## 2. ดัน 4 · บึงพิษมรกต 💀 (ปลดล็อกหลังเคลียร์ดัน 3)
| ห้อง | มอน |
|---|---|
| เวฟ 1 ริมบึง | คางคกพิษ x2, หมอผีกิ้งก่า |
| เวฟ 2 รังต่อ | ต่อยักษ์ x2, ทหารเต่าโล่, หมอผีกิ้งก่า |
| **ดวล 1-1** (40 เทิร์น) | สุ่ม เวโนมิร่า / กลาเซียร์ |
| เวฟ 3 ดงคางคกระเบิด | คางคกพองลม x2, ทหารเต่าโล่, ต่อยักษ์ |
| เวฟ 4 กำแพงกระดอง | ทหารเต่าโล่ x2, หมอผีกิ้งก่า, คางคกพิษ |
| **บอส ไฮดรามรกต** (45 เทิร์น) | 3 เฟส |

- คางคกพิษ: ตีติดพิษ 2 · หมอผีกิ้งก่า: ฮีล 22% ทุก 2 เทิร์น (**ฆ่าก่อน!**) · ต่อยักษ์: เร็ว Flee สูง ต่อย 2 ที ติดพิษ · ทหารเต่าโล่: P.DEF 120 + โล่ 15% ให้ทั้งทีมทุก 3 เทิร์น · คางคกพองลม: ตายแล้วระเบิด
- **เวโนมิร่า ราชินีใยพิษ** (mini): กัดติดพิษ 2 · ทุก 3 เทิร์นพ่นใย = ใบ้ 2 เทิร์น · ชาร์จ "ห่อใยพิษ" (BREAK 7%) โดนแล้วแข็งเสียเทิร์น + พิษ 3 · HP < 50% ฟักลูกแมงมุม 2 ตัว
- **กลาเซียร์ ยักษ์ธารน้ำแข็ง** (mini): P.DEF 100 (คริ/เวททะลุ) · ทุกทีเกราะเราแตก · ชาร์จทุก 3 เทิร์น ทุบแล้วแข็ง · HP < 40% เกราะน้ำแข็ง (โล่ 18%) + แรงขึ้น + ล้างสถานะตัวเอง
- **ไฮดรามรกต** (บอส): เฟส 1 กัดติดพิษ · **66%** หัวที่สองงอก: ฮีล 10% + เรียกคางคกพิษ 2 + แรง x1.15 + ตีติดพิษและไฟ · **33%** หัวที่สาม: เร็ว x1.3 ชาร์จทุก 2 เทิร์น กัดแล้วพิษ 4 + เกราะแตก

## 3. ดัน 5 · บัลลังก์อเวจี 💀 (ปลดล็อกหลังเคลียร์ดัน 4)
| ห้อง | มอน |
|---|---|
| เวฟ 1 ประตูนรก | อัศวินนรก, ปีศาจระเบิด x2 |
| เวฟ 2 โถงคำสาป | แม่มดคำสาป, นักบวชมรณะ, อัศวินนรก |
| **ดวล 1-1** (40 เทิร์น) | สุ่ม มิราจ / บารัค |
| เวฟ 3 ระเบียงกระจก | ภูตกระจก x2, ปีศาจระเบิด, แม่มดคำสาป |
| เวฟ 4 กองทัพศพ | อัศวินนรก x2, นักบวชมรณะ, ปีศาจระเบิด |
| **บอส จอมลิชโมรเดคัส** (50 เทิร์น) | 3 เฟส |

- อัศวินนรก: เกราะแตก + โห่ร้องทั้งทีมแรง +30% · แม่มดคำสาป: ไฟลุก + สาปอ่อนแรง · ปีศาจระเบิด: เร็ว ตายแล้วระเบิด · นักบวชมรณะ: **ปลุกศพ** + ฮีล · ภูตกระจก: สะท้อน 25%
- **มิราจ ภูตกระจกพันหน้า** (mini): สะท้อน 30% · ตีทีอ่อนแรง · ชาร์จแล้วอ่อนแรง+ใบ้ · HP < 50% แตกเศษกระจก 2 (ระเบิดได้) สะท้อน 40%
- **บารัค ขุนศึกคลั่งโลหิต** (mini): ทุก 3 เทิร์นแรงขึ้น +25% **สะสมไม่หาย** = แข่งดาเมจ · ดูดเลือด 20% · เกราะแตก · HP < 30% เร็ว x1.5
- **จอมลิชโมรเดคัส** (บอส): เวท ติดไฟ · ทุก 4 เทิร์นสาป (อ่อนแรง+เกราะแตก) · **70%** โล่กระดูก 12% + สะท้อน 20% + ปีศาจระเบิด 2 · **35%** พิธีกรรมสุดท้าย: ฮีล 8% เร็ว x1.3 แรง x1.15 ชาร์จทุก 2 เทิร์น ชาร์จแล้วใบ้ + เรียกอัศวินนรก

## 4. รางวัล
**สกิลขั้นสูงสุดใหม่ 4 อัน** (pool รวม 12 · ชนะ mini boss เสนอ 2 ใบประจำตัว + 1 สุ่ม · `data/relics.ts`)
| สกิล | จาก | ผล |
|---|---|---|
| ✨ กายบริสุทธิ์ | เวโนมิร่า (+ไฟโลกันตร์) | กันสถานะผิดปกติทั้งหมด + ฟื้น HP 3%/เทิร์น |
| 🛡️ โล่อมตะ | กลาเซียร์ (+ยุคน้ำแข็ง) | เริ่มทุกการต่อสู้โล่ 35% HP · มีโล่อยู่ ดาเมจ +20% |
| 🌵 เกราะหนามอเวจี | มิราจ (+ปัดป้องไร้ที่ติ) | โดนตีแล้วคนตีโดนสะท้อน 50% · ดาเมจสะท้อนของมอนเข้าเราลดครึ่ง |
| 🪓 เพชฌฆาต | บารัค (+สัญญาเลือด) | ตีศัตรู HP < 35% แรง +60% · ฆ่าได้ท่าไม้ตายเร็วขึ้น 1 เทิร์น |

**ของร้านใหม่** (เครื่องประดับ ใส่ได้ทุกอาชีพ): 🧿 เครื่องรางล้างพิษ (หลังล้มอัศวินมรณะ, 1600 zeny, กันสถานะ 35%) · 💚 หัวใจไฮดรา (หลังล้มไฮดรา, 2600 zeny, ทุกค่า +3, ฟื้น HP, กันสถานะ 25%)
เพชรเคลียร์ครั้งแรกใช้ระบบเดิม (`clearsBy.d4`, `clearsBy.d5`)
