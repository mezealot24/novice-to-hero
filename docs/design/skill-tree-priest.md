# ✨ นักบวช (Priest) — Skill Tree + Talent สเปกเต็ม

> สถานะ: **ร่างรอคิวอนุมัติ** · 2026-11-03 · ต่อยอดจาก `skill-tree-v1.md` (หมวดนักบวช)
> ในโค้ดอาชีพนี้ชื่อ `cleric` (แสดงผล "นักบวช") · ใช้กติกากลางของ framework (แต้ม/ปลดล็อก/รีเซ็ต) ไม่เปลี่ยน

## TL;DR (so what)

- **ตัวตนนักบวช = "ฮีลคือดาเมจ"** ไม่ใช่แท็งก์ที่ยืนเฉยๆ → รองรับกติกา **20 เทิร์น/ไฟต์** ที่คิวเพิ่งขอ
- **สาย A แสงคุ้มครอง**: ยืนนาน แต่ **โล่ที่รับดาเมจ + ฮีล จะสะท้อนเป็นดาเมจ** → สายแท็งก์ก็ยังฆ่าบอสทันเวลา
- **สาย B ตัดสิน**: ตีแรง แสงยิงหลายตัว **ฮีลช้าลงแต่แรงขึ้น** → มีเทิร์นตีเยอะขึ้นจริง
- **หอกแสง 🔱** (ไอเดียจากคิว): หอกลอยตีทุกตัว · ult ทุกคนได้ 2 เล่ม · ทาเลนต์สายหอก 3 ตัว
- **ทาเลนต์ 4 แถว (Job Lv 5/10/20/30) แถวละ 1 จาก 3 · Rank 1–2** ใช้แต้มทาเลนต์แยกกอง (1 TP/5 Job Lv) · shape เดียวกับทุกอาชีพ
- เปลี่ยนจากร่าง v1 สามจุด (ดูหัวข้อ 5): ชื่อโหนดซ้ำการ์ด, เอา counter ออก, ย้าย "ฟื้นคืน" ไปเป็นทาเลนต์

## 1. ปัญหาที่ต้องแก้ (ทำไมต้องมีทางทำดาเมจ)

| สิ่งที่เห็นในโค้ดตอนนี้ | ผล |
|---|---|
| สกิลออโต้ **ฮีลทุกครั้งที่ HP < 75%** แทนการยิงแสง | ตอนสู้บอส นักบวชใช้เทิร์นไปกับฮีลเยอะ ดาเมจแทบไม่มา |
| แสงศักดิ์สิทธิ์ยิง 2 ตัวหน้า 1.6x M.ATK · เวทไม่พลาด ไม่โดน P.DEF | เป็นดาเมจหลักทางเดียว |
| บอสดัน 2 (จ่าฝูงเงา) HP 1,350 + เรียกลูกน้อง | ประเมินคร่าวๆ: แสง ~80/ครั้ง → ~17 เทิร์นถ้ายิงล้วน · **มีฮีลแทรก = เกิน 20 เทิร์นแน่นอน** |

> ⚠️ ตัวเลข M.ATK ~50 ที่ Job Lv 15 เป็นการประเมิน ยังไม่ได้วัด · จะวัดจริงด้วยบอทใน Phase 2

**เป้าหมาย (วัดด้วยบอท Job Lv 15, ของสายนักบวชดัน 1):** บอสดัน 2 จบใน **≤ 16 เทิร์นฮีโร่ (สาย A)** และ **≤ 12 (สาย B)** · ชนะดัน 2 ราว 8–11/12 เหมือนอาชีพอื่น

## 2. Skill Tree

กติกากลาง (จาก v1): โหนด 1–3 อัปได้ 3 เลเวล · capstone ★ 1 เลเวล ได้อาชีพละ 1 อัน · โหนดที่ N ต้องลงในสายนั้นแล้ว (N−1)×2 แต้ม · capstone ต้องลงในสาย 6 แต้ม · รีเซ็ตฟรี
ป้าย: ✅ = stat ที่มีอยู่แล้ว · 🛠️ = กลไกใหม่

### สาย A: 🛡️ แสงคุ้มครอง (Sanctuary) — "ยืนนาน แล้วให้ศัตรูเจ็บเอง"

| # | โหนด | Lv1 / Lv2 / Lv3 | ทำงานยังไง | ใช้ stat |
|---|---|---|---|---|
| A1 | ✅ **พรอุ่นไอ** | ฮีลแรง +8% / +16% / +24% | บวก `healAmp` ตรงๆ | healAmp |
| A2 | ✅ **เกราะแสง** | โล่แรง +8% · โล่ต้นเวฟ 3% HP / +16% · 6% / +24% · 9% | บวก `shieldAmp` + `waveShield` (เติมโล่ทุกต้นเวฟ ไม่ซ้อน) | shieldAmp, waveShield |
| A3 | 🛠️ **หนามแสง** | สะท้อน 25% / 50% / 75% ของดาเมจที่โล่ดูดไว้ | มอนตีโดนโล่ → ยิงดาเมจศักดิ์สิทธิ์ (เวท ไม่พลาด) กลับใส่ตัวที่ตี · **โดนบอสได้** | shield |
| ★A | 🛠️ **ไฟชำระ** (Atonement) | — | (1) ฮีลส่วนที่เกิน HP เต็ม กลายเป็นโล่ (สูงสุด 30% HP) (2) **ทุกครั้งที่ฮีล ยิงดาเมจ 60% ของยอดฮีล (รวมส่วนเกิน) ใส่ตัวหน้าสุด** | healAmp, shieldAmp |

> สาย A ทั้งสาย: ยิ่งอึด ยิ่งตีแรง · บอสตีโล่ = บอสเจ็บ · ฮีล = ตี · ไม่ต้องยืนรอนาน

### สาย B: ⚖️ ตัดสิน (Judgement) — "ตีแรง ฮีลเท่าที่จำเป็น"

| # | โหนด | Lv1 / Lv2 / Lv3 | ทำงานยังไง | ใช้ stat |
|---|---|---|---|---|
| B1 | ✅ **แสงคม** | M.ATK +5 / +10 / +15 | บวก `matk` | matk |
| B2 | 🛠️ **ตัดสินหมู่** | แสงยิง 3 ตัว / 4 ตัว / 4 ตัว +15% ดาเมจ | เพิ่มเป้าแสงศักดิ์สิทธิ์ (เดิม 2) | — |
| B3 | 🛠️ **ใจนิ่ง** | ฮีลเมื่อ HP < 65% / 55% / 45% · ฮีลแรงขึ้น +10% / +20% / +30% | เลื่อนเกณฑ์ฮีลของสกิลออโต้ (เดิม 75%) → **เทิร์นตีมากขึ้น** แต่ฮีลทีเดียวก้อนใหญ่ | healAmp |
| ★B | 🛠️ **วันพิพากษา** | — | ทุก **แสงครั้งที่ 3** กลายเป็น "พิพากษา": ใส่ทุกตัว 2.2x M.ATK + **ตราบาป** 2 เทิร์น (ตัวที่ติดรับดาเมจจากทุกแหล่ง +15%) | matk |

> ตราบาปช่วยสายเดียวกันเอง และคอมโบกับ **หนามแสง** ได้ถ้าคนลงข้ามสาย (ลงสาย A ถึง A3 + capstone B ได้ เพราะ capstone เลือกได้อันเดียว)

## 3. ทาเลนต์ (Talents)

**กติกา (shape กลางที่ทุกอาชีพใช้ร่วมกัน · คิวอัปเดต 2026-11-03):**
- ใช้ **แต้มทาเลนต์ (TP) แยกกอง**: ได้ 1 TP ทุก 5 Job Lv (Lv40 = 8 TP) · ไม่ปนกับแต้มสกิล
- 4 แถว เปิดที่ **Job Lv 5 / 10 / 20 / 30** · **แถวละเลือกได้ 1 อัน** จาก 3
- แต่ละอันมี **Rank 1–2** (rank ละ 1 TP) → ลงเต็มทุกแถว = 8 TP พอดีที่ Lv40
- รีเซ็ตฟรีในเมือง (ห้ามเปลี่ยนกลางดัน)
- ทาเลนต์ = **เปลี่ยนวิธีเล่น** ไม่ใช่ +stat ล้วน (stat อยู่ใน tree แล้ว)
- หลักตั้งตัวเลข: Rank 1 ≈ 60% ของ Rank 2 → ลงแถวใหม่ rank 1 คุ้มกว่าอัป rank 2 นิดหน่อย (ให้กระจายก่อน)

| แถว | ตัวเลือก | Rank 1 | Rank 2 | เหมาะกับ |
|---|---|---|---|---|
| **I · Job Lv 5** (คำปฏิญาณ) | 💧 **สมาธิ** | ฟื้น Mana +20% | ฟื้น Mana +35% | ทุกสาย |
| | 🔱 **หอกเปิดศึก** | เริ่มทุกไฟต์ด้วยหอกแสง 2 เล่ม | 3 เล่ม | สายหอก / ล้างเวฟ |
| | 🛡️ **ร่างพร** | เริ่มไฟต์บอส/มินิบอสด้วยโล่ 12% HP | โล่ 20% HP | สาย A / มือใหม่ |
| **II · Job Lv 10** (ปรับ ult "พรคุ้มครอง") | 🌿 **พรยืนยาว** | ult แถม regen 2% HP/เทิร์น 3 เทิร์น | 3% HP/เทิร์น 3 เทิร์น | สาย A |
| | ☀️ **แสงลงทัณฑ์** | ult แถมดาเมจ 1.0x M.ATK ใส่ทุกตัว | 1.6x M.ATK | สาย B / ทำเวลา |
| | 🕊️ **ใต้ปีกเทพ** | กด ult ตอนบอสชาร์จ: โล่ x1.5 | โล่ x2 | ทุกสาย มือใหม่ |
| **III · Job Lv 20** (ปรับสกิลออโต้) | 🔱 **หอกรายเทิร์น** | ได้หอกแสง 1 เล่มทุก 2 เทิร์นฮีโร่ | ทุกเทิร์น | สายหอก |
| | 🍀 **ปาฏิหาริย์** | แสงและหอกแสงคริได้ 10% (ตัวคูณคริของเกม) | 18% | สาย B / สายหอก |
| | 🌟 **แสงชุบชีวิต** | แสงฮีลตัวเอง 6% ของดาเมจที่ทำ | 10% | ลูกผสม |
| **IV · Job Lv 30** (ตัวตน) | 👼 **เทวดาคุ้มครอง** | ล้มครั้งแรกต่อรอบ ลุกใหม่ HP 25% | HP 40% + โล่ 15% | สาย A |
| | 🔱 **หอกศักดิ์สิทธิ์** | หอกแสงแรง 30% → 45% M.ATK · หอกแต่ละเล่มฮีล 0.5% HP | 60% M.ATK · ฮีล 1% HP | สายหอก (ปลายเกม) |
| | 🌅 **อรุณรุ่ง** | ตั้งแต่เทิร์นที่ 12 ดาเมจทุกแหล่ง +18% | +30% | **กันโดนตัดเวลา 20 เทิร์น** |

### 3.1 🔱 หอกแสง (Light Spear) — สายที่ 3 ผ่านทาเลนต์

> ไอเดียจากที่คิวให้ดู: Capybara Go มีสกิลตระกูล "Light Spear" (หอกตีทุกตัว 30% ATK ได้หอกตอนเริ่มไฟต์ / ทุกเทิร์น / ตอนสวน / ตอนใช้ rage skill · ระดับ Mythic เปลี่ยนเป็น Magic Spear · Immortal "Angel Power" ได้หอกทุกครั้งที่ตีธรรมดา + Holy Light ฮีล) หนูหยิบแค่ **กลไก** มาปรับเป็นของนักบวชเรา ชื่อและตัวเลขเป็นของเราเอง

- **หอกแสง 1 เล่ม = 30% M.ATK ใส่มอนทุกตัว** · เป็นเวท (ไม่พลาด ไม่โดน P.DEF) · ยิงตอนจบเทิร์นฮีโร่ · สะสมรอยิงได้สูงสุด 8 เล่ม
- **นักบวชทุกคนได้หอก**: ult "พรคุ้มครอง" เสกหอก 2 เล่ม (ไม่ต้องลงแต้ม) → เห็นกลไกตั้งแต่เปลี่ยนอาชีพ
- **ทาเลนต์ 3 ตัวต่อกันเป็น "สายหอก"**: หอกเปิดศึก (แถว I) → หอกรายเทิร์น (แถว III) → หอกศักดิ์สิทธิ์ (แถว IV) · ใช้ 6 TP ถ้าเต็ม
- ใช้ได้กับ **ทั้งสาย A และ B** ของ tree (คนละกองแต้ม) → build ไม่ซ้ำกัน
- **จุดเด่น**: กวาดลูกน้องบอส/เวฟฝูง · **จุดอ่อน**: เล่มละเบา ไม่ใช่ตัวล้มบอสหลัก (บอสยังพึ่งแสง/หนามแสง/ไฟชำระ)
- ตัวเลขคร่าวๆ (M.ATK ~50): หอก 1 เล่ม ≈ 15 ใส่ทุกตัว · สายหอกเต็ม ≈ 30/เล่ม × 1–3 เล่ม/เทิร์น
- ⚠️ ข้อมูลอ้างอิงจาก wiki/ไกด์ (capybara-go.game-vault.net, theriagames.com ปี 2025) ไม่ได้ยืนยันในเกมจริง
- ตัดออกเพื่อให้มีที่: ค้อนศรัทธา, แสงคู่, นักรบแสง

> กติกาคริ (คิว 2026-11-03): คริไม่ให้โล่ · เวทคริได้เฉพาะเมื่อมีทาเลนต์/ไอเทม/การ์ดที่ให้ "เวทคริ" (stat ใหม่ `spellCrit`) · ฮีลยังคริไม่ได้ → "ปาฏิหาริย์" เปลี่ยนเป็นแสง/หอกคริได้
> เทวดาคุ้มครอง: ถ้ามีการ์ด Phoenix ด้วย ใช้ Phoenix ก่อน (ไม่ซ้อนในไฟต์เดียว)
> ในโค้ด: ทาเลนต์ที่เป็นตัวเลขล้วน (สมาธิ) ใช้ `mod` · ที่เปลี่ยนพฤติกรรมต้องเพิ่ม Stats flag ใน `game-data.ts` แล้วอ่านใน `BattleScene` → รอดู API rank จาก framework ก่อนลงมือ

## 4. ตรงกับกติกา 20 เทิร์นยังไง

- สาย A: ดาเมจมาจาก **หนามแสง** (บอสยิ่งตีแรงยิ่งเจ็บ) + **ไฟชำระ** (ฮีลทุกครั้ง = ตี) → ไม่ต้องยืนตายเวลา
- สาย B: **ใจนิ่ง** ลดเทิร์นที่เสียไปกับฮีล + **ตัดสินหมู่/วันพิพากษา** กวาดลูกน้องบอส
- ทาเลนต์ **อรุณรุ่ง** และ **แสงลงทัณฑ์** เป็นทางออกตรงๆ สำหรับคนที่ไฟต์ลากยาว
- ⚠️ ยังไม่รู้ว่าครบ 20 เทิร์นแล้ว "แพ้" หรือ "บอสคลั่ง" · หนูออกแบบโดยถือว่า **นับเฉพาะเทิร์นฮีโร่** และครบแล้วแพ้ ถ้า framework เลือกแบบอื่นตัวเลขเป้าหมายในหัวข้อ 1 ปรับตาม

| สาย B + หอกเปิดศึก + แสงลงทัณฑ์ | 12/12 | 13–16 | 1–2 |

- ไม่มีใครโดนตัดเวลา · สาย A ช้าแต่ปลอดภัย สาย B เร็วเกือบ 2 เท่า ✅ ตามที่ตั้งใจ

- เทวดาคุ้มครองในโค้ด = revive +1 → **นับรวมกับการ์ดฟีนิกซ์** (ลุกได้ 2 ครั้งถ้ามีทั้งคู่) ง่ายกว่าแบบ "ใช้ฟีนิกซ์ก่อน"

## 6. ความเสี่ยง (SA note)
