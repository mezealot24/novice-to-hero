## TL;DR (อ่านแค่นี้ก็พอ)

- **เกมตอนนี้ "ระบบเยอะแล้ว แต่ยังไม่สมดุล"** มี 5 อาชีพ, skill web, อุปกรณ์ 6 ช่อง, การ์ด, Forge, 5 ดันเจี้ยน, relic, event ครบ

- **ลำดับที่ตุ๊กตาแนะนำ:**
  1. ปิดงานที่ค้าง: Rebalance อาชีพ (Forge phase 2 ขึ้น v39 แล้ว)
  2. **Event v2** (เอกสารนี้): ทำง่าย ใช้ data เป็นหลัก ทำให้ทุกรอบไม่ซ้ำ และทำให้ LUK กับ stat รองมีความหมาย
  3. อาชีพขั้น 2 (นำร่องที่ Swordsman: Berserker / Knight)
  4. Endgame loop: โหมดนรก / หอคอยไม่รู้จบ ที่ใช้ดันเดิมซ้ำ

- **Event v2 มี 3 ส่วนหลัก:**
  - 🎲 **Stat check**: event ใหม่ให้ลุ้นด้วย STR/INT/AGI/WIS/DEX แต่ละอาชีพมีจังหวะเด่นของตัวเอง ส่วน **LUK ลุ้นได้ทุกทาง** (โอกาสต่ำกว่า)

  - 💰 **Jackpot tier ตาม LUK**: LUK ถึง 20 / 35 / 50 ปลดล็อก jackpot ระดับสูงขึ้น ได้จังหวะแบบ "ว้าว" ชัดๆ

### 🍀 ปัญหาของสาย LUK ตอนนี้ (ตรงกับที่คิวถาม)

ตอนนี้ LUK ให้: คริ (3 LUK = 1%), หลบโชคดี, พรตำนาน, ดรอปหายาก, โอกาส event หายาก (10% + 0.5%/LUK, สูงสุด 30% ที่ LUK 40)

ปัญหาคือ **ผู้เล่นมองไม่เห็นว่า LUK ทำงาน**:
- event หายากมีแค่ 2 แบบ (หีบทอง, ภูต) และรางวัลกลางๆ (เพชร 2 + zeny)
- การบวก % แบบเงียบๆ ไม่มีจังหวะให้ตื่นเต้น
- ไม่มี "breakpoint" ให้ไล่ เช่น "อีก 5 LUK จะปลด X"

**หลักออกแบบของ Event v2:** LUK ต้อง **เห็นได้ · ลุ้นได้ · มีเป้าให้ไล่** แต่ต้อง **ไม่บังคับ** ทุกอาชีพยังเจอ event ดีๆ ได้

## ส่วนที่ 3 · Event v2

### 3.1 โครงสร้างใหม่

ตอนนี้: เคลียร์เวฟ (ที่ไม่ใช่บอส) → สุ่ม "หายากไหม?" → สุ่มจากตาราง 5 ธรรมดา / 2 หายาก

ใหม่: **3 ระดับ + มาตรดวง**

```
หลังเคลียร์เวฟ
 ├─ มาตรดวง 🍀 เต็ม 100? → JACKPOT (ตาม LUK tier) แล้วรีเซ็ตมาตร
 ├─ สุ่มหายาก (eventChance เดิม: 10% + 0.5%/LUK, cap 30%) → ตาราง RARE
 └─ ไม่งั้น → ตาราง COMMON
```

- event มี `tier: 'common' | 'rare' | 'jackpot'`, `minTier` (ดันขั้นต่ำ), `minLuk` (สำหรับ jackpot)
- ห้ามเจอ event เดียวกันซ้ำติดกันในรอบเดียว (ลด "อีกแล้วเหรอ")

### 3.2 🎲 Stat check (ให้ทุก stat มีที่ใช้)

option ที่ต้อง "ลุ้น" จะแสดง **% สำเร็จให้เห็นบนปุ่มเสมอ** และเมื่อกดจะมีอนิเมชันลูกเต๋า/วงล้อสั้นๆ

| Stat | โอกาส | ใช้กับ |
|---|---|---|
| STR | 30% + 1.5%/STR | งัดประตู, ยกหิน, ดึงดาบจากหิน |
| AGI | 30% + 1.5%/AGI | หลบกับดัก, วิ่งหนี, ขโมยของ |
| DEX | 30% + 1.5%/DEX | ปลดล็อกหีบ, ยิงเป้า |
| INT | 30% + 1.5%/INT | อ่านรูน, ไขปริศนา |
| WIS | 30% + 1.5%/WIS | ต้านคำสาป, คุยกับวิญญาณ |
| **🍀 LUK** | 15% + 1.2%/LUK | **ใช้แทน stat อื่นได้ทุก check** ("ลองเสี่ยงดวง") |

- cap 95% ทุกแบบ
- ใช้ base stat (รวมของ/การ์ด) ไม่รวม % บัฟ
- ตัวอย่าง: Thief LUK 40 → เสี่ยงดวง 63% ทุก check ส่วน Swordsman STR 40 → งัดประตู 90% แต่ check อื่นแย่
- **ผลพลอยได้:** ตอบโจทย์คิวเรื่อง "ให้ stat รองมีประโยชน์" (thread Rebalance) โดยไม่ต้องแก้สูตรต่อสู้

### 3.3 🍀 มาตรดวง (Fortune meter)

แถบเล็กๆ ใต้ HP ขึ้นรูปโคลเวอร์ ให้ผู้เล่น **เห็น** ว่า LUK กำลังทำงาน

| ได้แต้มจาก | แต้ม |
|---|---|
| ทุก event | 5 + LUK × 0.3 |
| ลุ้น check ไม่ผ่าน (ปลอบใจ) | +15 |
| เปิดหีบต้องสาป / เลือกทางเสี่ยง | +10 |
| เต็ม 100 | event ถัดไป = JACKPOT แล้วรีเซ็ต 0 |

- **เก็บข้ามรอบ** (save.fortune) เป็น pity แบบนุ่มๆ แพ้ก็ไม่เสียมาตร
- ประมาณการ (D2 = 5 event/รอบ):
  - LUK 0 → ~25/รอบ → jackpot ทุก ~4 รอบ
  - LUK 20 → ~55/รอบ → ทุก ~2 รอบ
  - LUK 40 → ~85/รอบ (+ check ไม่ผ่าน) → **เกือบทุกรอบ**
- เปิดใช้ตั้งแต่ D2 (D1 เป็นดันสอนเล่น)
- ตัวเลขต้องให้ bot วัดอีกที แต่เป้าคือ **สาย LUK เจอ jackpot ~1 ครั้งต่อรอบ อาชีพอื่น ~1 ครั้งต่อ 3-4 รอบ**

### 3.6 💰 ตาราง JACKPOT (มาจากมาตรดวงเต็มเท่านั้น)

ได้ jackpot ระดับสูงสุดที่ LUK ถึง (ใช้ LUK รวมของ/การ์ด) และจะเปิดฉากด้วยเอฟเฟกต์ทองเต็มจอ + เสียงพิเศษ เพื่อให้ "รู้สึก"

| LUK | Jackpot | รางวัล |
|---|---|---|
| 0+ | 🏦 **ห้องสมบัติลับ** | เลือก 2 จาก 4: พรหายาก / zeny x5 / เพชร 3 / ฮีลเต็ม + โล่ 30% |
| **20+** | 🎁 **หีบมิมิคราชา** | สู้มิมิคตัวโต (elite, 2 เฟส) ชนะ = **การ์ดมอนในดันนี้ 1 ใบแน่นอน** + zeny x5 · แพ้มิมิค ไม่จบรอบ แค่เสีย HP 30% แล้วมันหนีไป |
| **35+** | 🍀 **โคลเวอร์สี่แฉก** | event ที่เหลือทั้งหมดในรอบนี้เป็น **หายาก** + ทุก check ได้ +20% |
| **50+** | 🌠 **ดาวเจ็ดดวงเรียงตัว (777)** | เวฟถัดไปทุกการโจมตีคริแน่นอน + ทุกพรที่เหลือในรอบเป็นตำนาน (x2) + เพชร 5 |

- **ห้าม** jackpot ให้วัตถุดิบเพิ่มตาม LUK (ตามกฎใน item-acquisition-v1: วัตถุดิบไม่ scale ตาม LUK) ให้ได้แค่ "1 ชิ้นแน่นอน" เหมือนเดิม
- เพชรรวมต่อรอบจาก event ควร cap ไว้ (เช่น ≤ 8) ให้สอดคล้องกับนโยบาย gem ที่ "หาได้ฟรีแต่ไม่ท่วม"

### 3.7 ความยุติธรรมกับอาชีพที่ไม่เล่น LUK

- อาชีพไหนก็เจอ jackpot ได้ (มาตรเต็มช้ากว่า) และได้ห้องสมบัติลับระดับ 0+
- stat check ให้แต่ละอาชีพมีจังหวะเด่น: Swordsman งัดประตู, Mage อ่านรูน, Priest ต้านคำสาป, Archer ปลดล็อกหีบ, Thief หลบกับดัก + เสี่ยงดวง
- LUK คือ "ไพ่ตาย" ที่ลุ้นได้ทุกทางแต่ไม่ดีที่สุดในทางไหนเลย และเป็นทางเดียวที่ไป jackpot 35+/50+
- **Thief (AGI+LUK) ได้ประโยชน์ที่สุด** ซึ่งช่วย Thief ที่อ่อนอยู่ทางอ้อม แต่ไม่ใช่การแก้ balance หลัก (ต้องแก้ใน thread Rebalance อยู่ดี)

### 3.8 ไอเดียการ์ด/ของสาย LUK (เสริม ทำทีหลังได้)

- 🃏 การ์ด "โปริงทอง"-style ของเกมเรา: **การ์ดเจลล็อปทองคำ** (ดรอปจาก event เจลล็อปทองคำ) LUK +3, มาตรดวง +3/event
- 🎲 หมวก "ลูกเต๋าเสี่ยงโชค": ทุก check +10% แต่ check ไม่ผ่านโดนหนักขึ้น
- 🍀 talent ของ Thief: "มือขึ้น" ทุก check ที่ผ่านได้ zeny +10%
