# โรงตีเหล็ก UX v1: จาก "เมนูการ์ด" เป็น "ทั่งตีเหล็ก" (Design, 2026-11-07)

> สถานะ: **คิว Approve แล้ว 2026-11-07** (ตอบ 4 ข้อ: MVP = Cardforge + Salvage · Cardforge ใส่ได้ทุกอาชีพ · กติกา Salvage ตามที่เขียน · 3 โหมด + ตีแตกไม่เด้ง popup) · กำลัง implement เป็นเฟส P1-P6 บน `claude/forge-anvil`
> ต่อจาก: `docs/design/item-acquisition-v1.md` (กติกา forge ทั้งหมดยังเหมือนเดิม) · `craft-rules-v2.md` (กติกา craft ใหม่ คู่กับไฟล์นี้)
> รองรับของจากอีกเธรด: **Unique** (ใส่ได้ 2 ชิ้น บางชิ้นมีคำสาป) · **Taint** (ชื่อใน UI: Corrupt, สุ่มครั้งเดียวแล้วล็อกของ) · tower skip (ไม่อยู่ในโรงตีเหล็ก)
> Mockup: `craft-mockup.html` (เปิดในเบราว์เซอร์ได้เลย คลิกแท็บ/สถานะได้)

## 0. TL;DR (so what)
- ตอนนี้: **กริยามาก่อน ของมาทีหลัง** → ของชิ้นเดียวกระจายอยู่ 3 แท็บ (อัปขั้น / ตีบวก / 🎲 ป๊อปอัป)
- ใหม่: **ของมาก่อน** → เลือกของ 1 ชิ้น วางบน **ทั่ง** ตรงกลาง แล้วทุกกริยาอยู่รอบ ๆ มัน
- 5 แท็บ → **3 โหมด**: ⚒️ ทั่ง · 📜 สูตร · 🎒 คลัง
- **แถบต้นทุน (cost strip)** ที่เดียว ตำแหน่งเดียว ทุกกริยา → ตาไม่ต้องหา
- พลาด/แตก **ไม่เด้ง modal** อีกแล้ว → ผลโชว์บนทั่ง ตีต่อได้ทันที (ลดการกดจาก 2 เหลือ 1)
- **Pity meter โชว์ชัด** (ฐาน + pity + "ถ้าพลาดจะได้ +10%") แบบ Lost Ark
- Taint/Corrupt = กริยาเสี่ยงสุด → **กดค้าง 1.2 วิ** + ตารางผลลัพธ์ก่อนกด
- ไม่มีการใช้เพชรเพิ่ม · zeny sink เท่าเดิม (UX ไม่เปลี่ยนตัวเลข)

## 3. Information Architecture ใหม่

### 3.1 โหมด (แทน 5 แท็บ)

| โหมด | แทนแท็บเดิม | ทำอะไร |
|---|---|---|
| ⚒️ **ทั่ง** (default) | อัปขั้น + ตีบวก + 🎲 + ซ่อม + (ใหม่) Corrupt | เลือกของ 1 ชิ้น ทำทุกอย่างกับมัน |
| 📜 **สูตร** | สร้าง + (ใหม่) Cardforge + หลอมคืน | สร้างของใหม่ / หลอมของเก่า (ดู `craft-rules-v2.md`) |
| 🎒 **คลัง** | เชื้อ + วัตถุดิบ | ดูของในกอง ซื้อเชื้อ ย้ายของเป็นเชื้อ (เข้าน้อย เลยรวมกัน) |

### 3.2 Layout หลัก (960×576)

```

y56  ├─ [⚒️ทั่ง] [📜สูตร] [🎒คลัง]                 💬 "พลาดมา 2 ทีแล้ว ใกล้แล้ว!" ┤
y104 ├──────────────┬──────────────────────────┬───────────────────────────┤
     │ ITEM RAIL    │      ANVIL STAGE          │  VERB PANEL               │
     │ x16 w200     │      x228 w360            │  x600 w344                │
     │ [ใส่อยู่][ทั้งหมด]│                       │ [⬆️ขั้น][⚒️บวก][🎲ออปชัน][☠️]│

     │  🪖หมวก 💔   │     ★4 ปรมาจารย์ · ใส่อยู่   │                           │

     │  ...         │   ═══ ทั่ง ═══            │                           │

y500 ├──────────────┴──────── COST STRIP ─────────────────────────────────┤
     │ [🔩ดาบสั้น 1/1] [🔩เศษเกราะ 6/6] [🔱ตรา 1/1] [🪙190]   [ ⚒️ ตี +8 · 40% ] │
y576 └────────────────────────────────────────────────────────────────────┘
```

- **Item rail (ซ้าย)**: เรียงแบบเดิม (ใส่อยู่ก่อน แล้วตามช่อง) ห้ามสลับลำดับหลังตี (กฎเดิม L152-153)
  - แถวละ 46px (นิ้วกดได้ ≥44px) · 6 แถว/หน้า + ◀ ▶ ล่าง rail
  - ป้ายในแถว: `+7` · `★4` · `💔` แตก · `🔥2` pity สะสม · `👑` unique · `☠️` corrupt
  - กรอง 2 ปุ่ม: `ใส่อยู่` / `ทั้งหมด` (แทนปุ่ม "ของฉัน" ที่อยู่ไกล)
- **Anvil stage (กลาง)**: ไอคอนใหญ่ 96px กรอบสีตามขั้น (`GRADE.colors`) · ชื่อ +N · ★ · สถานะ · **preview ค่าก่อน→หลัง** ของกริยาที่เลือก
- **Verb panel (ขวา)**: แท็บไอคอน 4 อัน (เปลี่ยนเนื้อหาแค่ panel ไม่ rebuild ทั้งจอ)
- **Cost strip (ล่าง)**: ตำแหน่งเดียวกันทุกกริยา · chip ต่อวัตถุดิบ + ปุ่มหลักใหญ่ขวาสุด (ตำแหน่งนิ้วโป้งขวา)
- **ช่างพูด (บนขวา)**: บับเบิลสั้นที่ **เปลี่ยนตามสถานะ** (pity, แตก, max) แทนข้อความคงที่ L34

### 3.3 Flow
```
เข้าโรงตีเหล็ก ─► โหมดทั่ง (auto เลือกอาวุธที่ใส่อยู่)
   │ แตะของใน rail ─► ของขึ้นทั่ง (tween เลื่อนเข้า 180ms)
   │ verb ที่เปิดอยู่ "ค้างไว้" ข้ามของ (เลือก ⚒️ แล้วเปลี่ยนของ ยังอยู่ที่ ⚒️)
   │
   ├─ ของแตก 💔 ─► verb panel บังคับเป็น 🔧 ซ่อม (ปุ่ม 🔧 วัตถุดิบ / 💎10 ขนาดเท่ากัน · กฎ 3.6 เดิม)
   ├─ ของ Corrupt ☠️ ─► ⬆️ ⚒️ 🎲 ☠️ ขึ้นกุญแจ + เหตุผล "ถูก Corrupt แล้ว ย้อนไม่ได้" · ดูได้อย่างเดียว
   ├─ ของ Unique 👑 ─► เหมือนของปกติ + แถบคำสาปสีแดงใต้ชื่อ (ถ้ามี)
   └─ ของเริ่มต้น/ตีไม่ได้ ─► ไม่โชว์ใน rail (กฎ `refinable` เดิม)

โหมดสูตร: รายการสูตร ─► แตะ ─► stage โชว์ของที่จะได้ + cost strip ─► สร้าง ─► "ใส่เลย?" (เดิม)
          📌 ปักหมุด 1 สูตร ─► หน้าผลลัพธ์ดันขึ้น "📌 ของครบแล้ว!" เมื่อพอ
```

### 3.4 กริยาเชื่อมกันยังไง

| กริยา | เปิดเมื่อ | ปิด/ล็อกเมื่อ | หมายเหตุ |
|---|---|---|---|
| ⬆️ ขั้น | ของ `gradeCap > 1` | ★ ครบ cap · Corrupt | สำเร็จ 100% (เดิม) |
| ⚒️ ตีบวก | `refinable` | +10 · แตก · Corrupt | แตก → สลับไป 🔧 ซ่อม อัตโนมัติ |
| 🎲 ออปชัน | มี ≥1 บรรทัด (+5) | Corrupt | ยังไม่มีบรรทัด → โชว์ "ตีถึง +5 ก่อนนะ" แทนการซ่อนแท็บ |
| ☠️ Corrupt | ตามกติกาอีกเธรด | Corrupt แล้ว (ครั้งเดียว) | กดค้าง 1.2 วิ · แนะนำให้ทำ "ท้ายสุด" (ข้อความ) |
| 🔧 ซ่อม | แตก | — | โผล่แทน ⚒️ เฉพาะตอนแตก |
| 🃏 การ์ด | (ลิงก์) | — | ปุ่มเล็กบน stage → ไปหน้าอุปกรณ์ ไม่ทำซ้ำในโรงตีเหล็ก |

- ลำดับแท็บ verb = ลำดับที่ควรทำจริง (ขั้น → บวก → ออปชัน → Corrupt) · สอนผู้เล่นโดยไม่ต้องอธิบาย

## 4. Wireframes ต่อหน้าจอ

### 4.1 ทั่ง / ⚒️ ตีบวก (affordable)
```
┌ VERB: [⬆️] [⚒️•] [🎲] [☠️] ───────────┐
│ ตีบวก +7 → +8                          │
│ โอกาส  ███████████░░░░░░░  40%         │
│        ฐาน 30% ▓ + pity 10% ▒ (🔥1)    │
│        ถ้าพลาด: ครั้งหน้า 50% (+10%)    │
│ ได้: ค่าทั้งชิ้น +5% · ATK 34 → 36      │
```

## 5. Feedback & Juice (engine-neutral, Phaser-friendly)

**หลัก:** ความแรงตามความสำคัญ · ทุกอันกดข้ามได้ (แตะจอ = เร่งจบ) · ไม่มี particle emitter หนัก (เครื่องคิวอ่อน) → ใช้ Graphics + tween เท่านั้น สูงสุด ~20 ชิ้น/ครั้ง

### 5.1 ตารางเหตุการณ์

| เหตุการณ์ | ก่อนผล (anticipation) | ผล | เสียง (`sfx` เดิม) | ระยะ |
|---|---|---|---|---|
| ตี +1~+4 (100%) | ค้อนเคาะ 1 ครั้ง | ตัวเลข `+3` เด้ง (scale 1.4→1, Back.Out) | `clang` | 250ms |

| ได้ค่าพิเศษใหม่ (+5/+7/+10) | — | แถวบรรทัดใหม่ "พลิกการ์ด" (scaleX 0→1) · ทอง = ประกาย + `critBoom` | `pop` / ทอง `critBoom` | +400ms |

### 5.2 Pity meter (Lost Ark pattern)
- แถบเดียว 3 ชั้น: `▓ฐาน` (ส้ม) + `▒pity` (เขียว) + `░ghost +10% ถ้าพลาด` (เขียวโปร่ง กระพริบช้า)
- ตัวเลข: `40% = ฐาน 30 + pity 10`
- ป้าย `🔥N` ติดของใน rail (BDO pattern) → ผู้เล่นรู้ว่าชิ้นไหนสะสมไว้
- แตกแล้ว pity ยังอยู่ (กฎเดิม) → ข้อความในหน้าซ่อมย้ำ "pity เก็บไว้ให้"

### 5.3 โหมดตีเร็ว
- ตั้งค่า `⚡ ตีเร็ว` (เก็บใน save เป็น flag เล็ก หรือ localStorage) → anticipation เหลือ 0 · ผลยังโชว์ 200ms
- แตะจอระหว่างแอนิเมชัน = ข้ามไปผลทันที (ไม่ต้องตั้งค่า)
