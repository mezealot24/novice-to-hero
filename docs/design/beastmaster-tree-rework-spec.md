## 0. สรุปภาพรวมเชิงบริหาร (Executive Summary & Core Fantasy)

### 0.1 อัตลักษณ์ใหม่ของ Beastmaster (The Tri-Beast Master Fantasy)
บีสต์มาสเตอร์ (Beastmaster) ไม่ใช่เพียงแค่นักธนูที่มีสัตว์เลี้ยงเดินตามทีละตัว แต่คือ **"จอมทัพแห่งพงไพรผู้บัญชาการฝูงสัตว์ทั้งสาม"** โดยสัตว์เลี้ยงทั้ง 3 ตัว — 🦅 **เหยี่ยวเวหา (Hawk - RO Falconer)**, 🐗 **หมูป่าศิลา (Boar)**, และ 🐺 **หมาป่าโลหิต (Wolf)** — จะร่วมลงสนามต่อสู้เคียงบ่าเคียงไหล่กับฮีโร่ในทุกเวฟการต่อสู้อย่างพร้อมเพรียง 

ความลึกซึ้งของการเล่นถูกยกระดับผ่าน 3 เสาหลักสำคัญ:
1. **The Seven Combat Mechanics Weaving**: ผังทักษะ 20 โหนดถูกออกแบบใหม่แบบ Non-Monotonous โดยแทนที่การบวกตัวเลขดิบ (+% Stat) ด้วยการเชื่อมโยงระบบต่อสู้ใหม่ทั้ง 7 ประการ ได้แก่ **Grit (เกจความโกรธหมูป่า)**, **Guard/Share (การแบ่งรับดาเมจและพักฟื้น)**, **Frenzy (คลั่งตามสแตกเลือด)**, **Bleed (เลือดไหลตาม % เลือดมอน)**, **Mark (หมายหัวและระดมพล)**, **Blind (ละอองขนนกตาบอด)**, และ **Awakening (สภาวะปลุกพลังบรรพกาล 3 เทิร์น)**
2. **RO-Style Falconer Blitz Beat (สายนก INT / LUK แท้แบบ RO)**: เหยี่ยวถูกยกเครื่องให้สเกลตามจิตวิญญาณของ RO Hunter — **โอกาสโฉบออกขึ้นอยู่กับ `LUK`** และ **Main Damage per Hit มาจาก `INT` (`M.ATK`)** เป็นหลัก (สัดส่วน ~5.7:1 เทียบกับ `DEX`, เหมือนสูตร RO `INT/2` vs `DEX/10`) โดยตีเป็น **True Misc Damage (ไม่สน Flee, ทะลุ P.DEF & M.DEF 100%)** เปิดทางให้สาย Build `INT/LUK` Falconer เล่นได้จริงควบคู่กับสายธนู `DEX/AGI/LUK`
3. **"คู่หูพราน" Partner Passive Stances (`save.pet`)**: ผู้เล่นสามารถเลือก 1 ใน 3 สัตว์เป็น "คู่หูหลักประจำตัว" ในเมือง ซึ่งจะมอบ **ท่ายืนบัฟสถานะเฉพาะตัว (Hero Passive Stance)** ให้แก่ฮีโร่ตลอดการต่อสู้ ควบคู่ไปกับการกำหนดตัวที่จะกระโจนเคาน์เตอร์โจมตีซ้ำเมื่อฮีโร่โจมตีติดคริติคอล (`bm_s4` ★ พรานแห่งป่า)

### 0.2 กฎความเข้ากันได้ 100% (Zero Save Regression Guarantee)
- **รักษา Node IDs เดิมทุกตัว**: รหัสโหนดทั้งหมด `bm_h1` ถึง `bm_h4`, `bm_b1` ถึง `bm_b4`, `bm_w1` ถึง `bm_w4`, `bm_k1` ถึง `bm_k4`, และ `bm_s1` ถึง `bm_s4` ถูกรักษาไว้ครบถ้วน 100% ป้องกันปัญหา Save File Corruption
- **ระบบ Free Migration Reset**: ฟังก์ชัน `migrateBeastmasterRework` ใน `src/save.ts` จะขยับเวอร์ชัน migration เป็น `s.bmRework = 2` (จากเดิม v1 ที่ใช้ `bmRework = 1`) เพื่อคืนแต้มทักษะทั้งหมดของ Beastmaster เข้าสู่ `job2Points` อย่างปลอดภัยเพียง 1 ครั้งแบบ Idempotent สำหรับผู้เล่นทั้งเก่าและใหม่
- **การยึดหลัก Turn-Based**: ทุกกลไกคำนวณตามรอบเทิร์นของฮีโร่ (Hero Turn), เกจความเร็ว (Turn Gauge), หรือจำนวนครั้งที่ลงมือ (Action Count) โดยไม่มีการใช้หน่วยเวลาเรียลไทม์ (วินาที/deltaTime) เข้ามาปะปน

### 1.1 กลไก RO Falconer Blitz Beat Engine (LUK Chance + INT/M.ATK Main Damage)
เพื่อคงเอกลักษณ์ Hunter สาย RO (Pre-Renewal: `Damage/hit = 80 + 6*SteelCrow + 2*floor(INT/2) + 2*floor(DEX/10)`, `Auto-Blitz = 0.3%*LUK`, ไม่สน DEF/MDEF/Flee) โดยปรับสเกลให้เติบโตทันดันเจี้ยน D1–D10 และ Tower (ที่ `STAT_RULES.max = 999` และอาวุธ/การ์ดบวก `M.ATK` โตตามขั้น):

1. **โอกาสโฉบออก (LUK-Driven Auto-Blitz)**:
   $$\text{hawkChance}(\text{st}, \text{luk}) = \min\left(\text{cap},\ 0.05 + 0.004 \times \text{luk} + \text{st.j2HawkChance}\right)$$
   - `hawkChance: 0.05` (5% ฐาน), `hawkLuk: 0.004` (`+0.4%/LUK` — เช่น LUK 100 = +40%, รวมกับ `bm_h1` Lv 3 (+15%) = ชนเพดาน `0.60` พอดี; เมื่อเลือก **🦅 Skyhunter Stance** เพดานขยายเป็น `0.75`).
   - ในสภาวะ Awakening โอกาสโฉบคูณ 2 (`min(1, chance * 2)`).
2. **Main Damage per Hit (INT / M.ATK Primary + Minor DEX, RO 5.7:1 Ratio)**:
   $$\text{FALCON\_MIX} = \{\text{matk}: 0.85,\ \text{atk}: 0.15\}$$
   $$\text{Falcon Power}(\text{st}, \text{int}, \text{dex}) = (0.85 \times \text{st.matk}) + (0.15 \times \text{st.atk}) + (\text{st.j2HawkIntAdd} \times \text{int}) + (\text{st.j2HawkDexToMatk} \times \text{dex})$$
   - เนื่องจากใน `PER_POINT` ของเกม `1 INT = +2 M.ATK` และ `1 DEX = +2 P.ATK` (สำหรับ Archer) จึงได้น้ำหนัก `1 INT = 1.70` vs `1 DEX = 0.30` (**อัตราส่วน ≈ 5.67 : 1** ใกล้เคียงสูตร RO `INT/2` vs `DEX/10` ที่ `5 : 1`), และยังคงสเกลจากอุปกรณ์/การ์ดสาย `M.ATK` ใน Endgame ได้เต็มที่.
   - **การคำนวณผ่าน `magicPower(st)` Pattern** (อ้างอิง `mageAutoRatio` ใน `src/data/skill-math.ts`): ใช้ helper `falconMul(st, int, dex)` แปลง `Falcon Power` ให้อยู่ในหน่วยของ `magicPower(st)` เมื่อเรียก `c.hitOne(mul, true, '#f2d24b', true, { mark: true, blind, pierce: 1 })` ภายใต้ `noPetCrit` (หรือเปิด Falcon Crit เฉพาะเมื่อมี `bm_t4_hawk`).
3. **RO Misc True Hit Properties**:
   - **ไม่พลาดเป้า (`sureHit = true`)**: ข้ามการเช็ก Flee ของศัตรู 100%
   - **ทะลุเกราะกายภาพและเวท (`pierce = 1`)**: ใน `BattleScene.strike` เมื่อ `pierce >= 1` ให้ข้ามทั้ง `m.def.def` และ `m.def.mdef` (ให้เหมือน Misc Damage ของ RO ที่ไม่ถูกหักด้วย DEF/MDEF)
   - **ความสม่ำเสมอแบบ Misc**: โดยปกติ Blitz Beat จะไม่ติดคริติคอล (รันภายใต้ `noPetCrit`) เว้นแต่ปลดล็อก Talent IV `bm_t4_hawk` (🦅 พายุจิกสวรรค์) ที่เปิดสิทธิ์ **Falcon Crit** บนเป้าหมายที่ติด 🏷️ Prey Mark.

## 2. R1: ผังทักษะ Beastmaster ฉบับยกเครื่อง (Skill Tree Redesign Specification)

### 2.1 สถาปัตยกรรมโครงสร้างผังทักษะ
- **รากฐานพลังอัตโนมัติ (2 Power Roots)**: ปลดล็อกทันทีเมื่อเปลี่ยนอาชีพเป็น Beastmaster
  - `beastmaster_s3p`: **📯 สั่งลุย (Pack Command)** — สกิลกดใช้งาน (Active Skill 3) ใช้ Energy 30 หน่วย สั่งสัตว์ทั้ง 3 ตัวลงมือพร้อมกันทันที
  - `beastmaster_u2p`: **🐾 ปลุกพลังฝูงบรรพกาล (Call of the Primeval Pack)** — อัลติเมตขั้น 2 (Ultimate Skill) แปลงสภาพเข้าสู่สถานะ Awakening นาน 3 เทิร์นฮีโร่
- **โครงสร้างโหนด 5 สาย × 4 ชั้น (20 Nodes)**:
  - สาย `bm_h`: สายฟ้า (Hawk - แม่นยำ / หมายหัว / ขัดขวาง)
  - สาย `bm_b`: สายป่า (Boar - ปราการ / แบ่งดาเมจ / แรงฮึด Grit)
  - สาย `bm_w`: สายเขี้ยว (Wolf - เลือดไหล / คลั่งความเร็ว / ขย้ำปลิดชีพ)

  - สาย `bm_s`: สายสัญชาตญาณ (Hunter's Instinct - บัฟฮีโร่ตามฝูง / เคาน์เตอร์คริติคอล)
- **ทาเลนต์ 4 แถว (12 Talents)**: ปลดล็อกตามระดับ Job2 Lv 5, 10, 20, 30 โดยแถวที่ 4 เป็นการเลือกความเชี่ยวชาญเฉพาะทางของสัตว์ (Specialization Capstones)

#### `bm_h1` — 🦅 ตาเหยี่ยว (Keen Eye)
- **ระดับสูงสุด**: 3 (ขยายเป็น 5 ด้วยกฎ Stretch)
- **หมวดหมู่**: ปรับปรุงอัตราเกิดและปฏิสัมพันธ์ต่อเป้าหมายที่ติด Mark
- **กลไกการทำงาน**:
  - เพิ่มโอกาสเกิด Blitz Beat พื้นฐาน: `+5%/lv` (Lv 3 = +15%, Lv 5 = +25%)
  - มอบค่า `HIT` ให้แก่ฮีโร่: `+8/lv` (Lv 3 = +24, Lv 5 = +40)
  - **Mechanic Interaction**: การโจมตีของฮีโร่และเหยี่ยวใส่เป้าหมายที่ติด 🏷️ Prey Mark จะเมินเฉยค่า Flee ของศัตรูลง `15%/lv` (Lv 3 = 45%, Lv 5 = 75%)
- **คำอธิบายในเกม**:
  - *ตอนนี้*: `Blitz Beat โอกาส +${lv*5}% · ฮีโร่ HIT +${lv*8} · การโจมตีใส่เป้า 🏷️ เมิน Flee ศัตรู ${lv*15}%`
- **Stat Modifiers**: `{ j2HawkChance: 0.05 * lv, hit: 8 * lv, j2MarkPierceFlee: 0.15 * lv }`

#### `bm_h2` — 🪶 กรงเล็บเหล็ก (Steel Crow — RO Hunter Passive)
- **ระดับสูงสุด**: 3 (ขยายเป็น 5 ด้วยกฎ Stretch)
- **หมวดหมู่**: เสริมพลังโจมตี Blitz Beat จาก INT/M.ATK และเจาะทะลวง Prey Mark
- **กลไกการทำงาน**:
  - เพิ่มตัวคูณพลังโจมตีของเหยี่ยว (`j2HawkMul`): `+15%/lv` ของ Falcon Power (`0.85 M.ATK + 0.15 P.ATK`)
  - **Mechanic Interaction (RO Steel Crow INT Scaling)**: เพิ่มดาเมจคงที่ต่อฮิตตามค่า `INT` ของฮีโร่ `+0.5/lv × INT` (`j2HawkIntAdd`: Lv 3 = `+1.5 × INT`, Lv 5 = `+2.5 × INT` ต่อฮิตก่อนคูณ — คิดรวมกับตัวคูณ True Damage!)
  - **Mechanic Interaction (Mark Amp)**: เพิ่มความแรงของสถานะ 🏷️ Prey Mark ที่เหยี่ยวแปะขึ้นอีก `+3%/lv` (จากฐาน 10% กลายเป็น 19% ที่ Lv 3 และ 25% ที่ Lv 5) และที่ระดับ 3 ขึ้นไป Mark อยู่นานขึ้น `+1 เทิร์น` (เป็น 3 เทิร์น)
- **คำอธิบายในเกม**:
  - *ตอนนี้*: `เหยี่ยวแรง +${lv*15}% (หลักจาก INT/M.ATK) · กรงเล็บเหล็ก: +${(lv*0.5).toFixed(1)}×INT ต่อฮิต · 🏷️ Mark แรงขึ้น +${lv*3}%${lv >= 3 ? " · อยู่นาน +1 เทิร์น" : ""}`
- **Stat Modifiers**: `{ j2HawkMul: 0.15 * lv, j2HawkIntAdd: 0.5 * lv, j2PreyMarkAdd: 0.03 * lv, j2PreyTurns: lv >= 3 ? 1 : 0 }`

## 3. R2: ระบบท่ายืนคู่หูพราน (Pet Selection Special Passive Stances & Mechanics)

### 3.1 หลักการออกแบบและสถาปัตยกรรม (Design Principle)
- **สัตว์ทั้ง 3 ตัวสู้ร่วมกันเสมอ**: ในฉากต่อสู้ สัตว์ทั้ง 3 ตัวจะถูก Spawn ลงสู่สนามทุกเวฟเสมอ (`packPow = 0.70`)
- **การเลือกคู่หูหลัก (`save.pet`)**: ผู้เล่นเลือกสัตว์ 1 ตัวเป็นคู่หูหลักประจำกาย ซึ่งทำหน้าที่ 2 ประการ:
  1. มอบ **Partner Passive Stance** ให้แก่ตัวฮีโร่ตลอดการต่อสู้ ปรับเปลี่ยนสไตล์การเล่นและสายสเตตัสที่โฟกัส
  2. กำหนดตัวที่จะพุ่งเข้าโจมตีโต้กลับเมื่อฮีโร่ติดคริติคอล (`bm_s4` ★ พรานแห่งป่า)

### 3.2 รายละเอียดคณิตศาสตร์และสูตรคำนวณของแต่ละ Stance

#### 1. 🦅 ท่าเหยี่ยวเวหา (Skyhunter Stance) — สถิตเวหาเหยี่ยวพราน (RO Falconer Build)
- **สัญลักษณ์และคีย์**: `save.pet === 'hawk'`
- **จุดเด่นทางยุทธวิธี**: ขยายโอกาสโฉบ LUK ทะลุเพดาน, ดันพลังเหยี่ยว INT/M.ATK (พร้อมแปลง DEX บางส่วนช่วยสายลูกผสม), แม่นยำสูง & เจาะจุดตาย 🏷️ Mark
- **สูตรคำนวณและสเตตัสที่มอบให้ฮีโร่**:
  $$\text{Hero LUK Bonus} = +15 \text{ (เพิ่มทั้ง Crit Rate และโอกาสโฉบ Blitz Beat)}$$
  $$\text{Auto-Blitz Proc Cap} = 75\% \text{ (ขยายเพดานจาก } 60\% \text{ เป็น } 75\% \text{)}$$
  $$\text{Hero HIT Bonus} = 15 + \lfloor 0.25 \times \text{DEX} \rfloor$$
  $$\text{Hero Crit Rate Bonus} = \min\left(15\%, 6\% + 0.05\% \times \text{LUK}\right)$$
  $$\text{Falcon DEX-to-MATK Resonance} = \lfloor 0.20 \times \text{DEX} \rfloor \text{ เป็นโบนัสพลังนก (ช่วยให้สายยิง DEX เล่นผสม Falcon ได้)}$$
  $$\text{Prey Mark Bonus} = \text{แรงขึ้นอีก } +5\% \text{ · ตีเป้า 🏷️ เมิน Flee } 100\% \text{ และ Crit DMG } +18\%$$
- **พฤติกรรมเมื่อฮีโร่โจมตีติดคริติคอล (`critPet`)**:
  - เหยี่ยวโฉบ **RO Blitz Beat** โจมตีซ้ำใส่เป้าหมายที่ฮีโร่คริทันที 1 ฮิตด้วยความเสียหาย **$100\%$ Falcon Power (`0.85 M.ATK + 0.15 P.ATK + Steel Crow INT`)**
  - การโจมตีนี้เป็น **True Misc Damage** (`sureHit: true`, `pierce: 1` ทะลุทั้ง P.DEF & M.DEF, ไม่สน Flee)
  - การันตีแปะสถานะ 🏷️ Prey Mark ทันที 2 เทิร์น (หรือขยายเวลาเดิมออกไปอีก 2 เทิร์น)
  - หากมีโหนด `bm_h4` ★ จะสั่ง Rally หมาป่าให้ได้เทิร์นทันทีเช่นกัน!

#### 2. 🐗 ท่าหมูป่าศิลา (Iron Tusk Stance) — สถิตหมูป่าศิลาพิทักษ์
- **สัญลักษณ์และคีย์**: `save.pet === 'boar'`
- **จุดเด่นทางยุทธวิธี**: ทนทาน อึดถึก ปราการเหล็ก แลกหมัด สะท้อนกลับ (Fortitude & Retaliatory Defense)
- **สูตรคำนวณและสเตตัสที่มอบให้ฮีโร่**:
  $$\text{Hero P.DEF Bonus} = \lfloor 0.15 \times \text{Base DEF} \rfloor + \lfloor 0.35 \times \text{VIT} \rfloor$$
  $$\text{Additional Damage Share} = +10\% \text{ (ทำให้หมูป่ารับแทน 45\% จากปกติ 35\%)}$$
  $$\text{Shield Amplification} = +20\% \text{ (ความหนาของโล่ทุกประเภทที่ฮีโร่ได้รับ)}$$
  $$\text{Emergency Grit Barrier} = \text{โล่ } 8\% \text{ Max HP ให้ฮีโร่ทันทีที่หมูป่าเกจ Rage เต็ม 100}$$
- **พฤติกรรมเมื่อฮีโร่โจมตีติดคริติคอล (`critPet`)**:
  - หมูป่าพุ่งชนเป้าหมายหน้าสุดทันที สร้างความเสียหายกายภาพ $(80\% + \text{j2BoarMul}) \times \text{P.ATK}$
  - ผลักเกจความเร็วของศัตรูถอยหลัง $-20$ หน่วย (ขัดจังหวะศัตรู)
  - มอบโล่ป้องกันฉุกเฉินให้ฮีโร่ทันที $5\%$ Max HP (นาน 2 เทิร์น)

#### 3. 🐺 ท่าหมาป่าโลหิต (Bloodpack Stance) — สถิตเขี้ยวหมาป่าโลหิต
- **สัญลักษณ์และคีย์**: `save.pet === 'wolf'`
- **จุดเด่นทางยุทธวิธี**: พลังโจมตีดุดัน เร่งเลือดไหล ดูดกลืนพลังชีวิต คลั่งความเร็วทะลุขีดจำกัด (Aggressive Bleed & Lifesteal)
- **สูตรคำนวณและสเตตัสที่มอบให้ฮีโร่**:
  $$\text{Hero P.ATK Bonus} = \lfloor 0.10 \times \text{Base P.ATK} \rfloor + \lfloor 0.30 \times \text{AGI} \rfloor$$
  $$\text{Bleed Damage Amplification} = +25\% \text{ ดาเมจต่อรอบของ Bleed ทั้งหมด}$$
  $$\text{Lifesteal on Wounded} = 4\% \text{ ดูดเลือดเมื่อฮีโร่โจมตีศัตรูที่มีสแตก Bleed } \ge 3 \text{ ชั้น}$$
  $$\text{Frenzy Cap Expansion} = \text{ขยายเพดาน Bloodscent Frenzy จาก 5 สแตกเป็น 7 สแตก (สูงสุด +21\% Speed)}$$
- **พฤติกรรมเมื่อฮีโร่โจมตีติดคริติคอล (`critPet`)**:
  - หมาป่ากระโจนกัดเป้าหมายทันที สร้างความเสียหาย $(70\% + \text{j2WolfMul}) \times \text{P.ATK}$
  - แปะสแตก Bleed ทันที $+2$ ชั้น
  - เร่งเกจความเร็วของตัวหมาป่าเอง $+50\%$ ทันที เพื่อเตรียมกัดซ้ำในรอบถัดไป

### 5.2 แผนเคสทดสอบหน่วยระบบ (Unit Test Suite Specification)

#### ชุดที่ 1: การทดสอบกลไกการต่อสู้ใน `tests/allies.test.ts`
1. **Test Case 1.1: Boar Damage Share & Cut**
   - *เงื่อนไข*: ฮีโร่ได้รับดาเมจหลังหักล้าง DEF เท่ากับ $100$ หน่วย, หมูป่ามี `boarShare = 0.35`, `boarCut = 0.30`
   - *ผลที่คาดหวัง*:
     - ส่วนที่หมูป่าแบ่งรับ: $\lfloor 100 \times 0.35 \rfloor = 35$ หน่วย
     - ดาเมจที่ฮีโร่ได้รับจริง: $100 - 35 = 65$ หน่วย
     - ดาเมจที่หมูป่าเสียเลือดจริง: $\text{round}(35 \times (1 - 0.30)) = 25$ หน่วย
2. **Test Case 1.2: Boar Grit / Rage Gauge Accumulation**
   - *เงื่อนไข*: หมูป่ามี $\text{Max HP} = 200$, ได้รับดาเมจ $50$ หน่วย, ค่า $boarRageK = 140$
   - *ผลที่คาดหวัง*:
     - ค่าเกจ Rage ที่เพิ่ม: $(50 / 200) \times 140 = 35.0$ หน่วย
     - หากได้รับดาเมจจนเกจ $\ge 100$: เกจรีเซ็ตเป็น $0$ และเรียกเมธอด `charge()` ทันที
3. **Test Case 1.3: Boar Down & Revival**
   - *เงื่อนไข*: หมูป่า HP ลดลงเหลือ $0$ จากการรับดาเมจแทน
   - *ผลที่คาดหวัง*:
     - `boar.down` ถูกตั้งค่าเป็น $3$ (หรือ $2$ เมื่อมี `bm_b4` ★)
     - `boar.dead` ต้องเป็น `false` เสมอ (ไม่ถูกลบออกจากสล็อต)
     - ฟังก์ชัน `readyAllies()` และ `livePets()` จะมองข้ามหมูป่าระหว่างที่ติดสถานะ `down > 0`
     - เมื่อผ่านไปครบเทิร์นที่กำหนด หมูป่าฟื้นเต็ม HP และพุ่งชนทันที
4. **Test Case 1.4: Wolf Bloodscent Frenzy Speed Scaling**
   - *เงื่อนไข*: มอนสเตอร์ตัวหน้ามีสแตก Bleed เท่ากับ $3$ ชั้น, `j2Frenzy = 0.03`
   - *ผลที่คาดหวัง*:
     - ความเร็วของฮีโร่และหมาป่าเพิ่มขึ้น: $1 + (0.03 \times 3) = 1.09$ เท่า (+9%)
     - หากมอนสเตอร์มีสแตก Bleed $8$ ชั้น (เกินเพดานฐาน 5): ความเร็วต้องถูกจำกัดที่ $1 + (0.03 \times 5) = 1.15$ เท่า (+15%)
5. **Test Case 1.5: Wolf Savage Crunch Execution Trigger**
   - *เงื่อนไข*: มีโหนด `bm_w4` ★ และมอนสเตอร์ตัวหน้ามีสแตก Mark หรือ HP ต่ำกว่า $35\%$
   - *ผลที่คาดหวัง*:
     - การโจมตีของหมาป่าติดคริติคอล $100\%$ แน่นอน
     - เกิดการฮีลให้ฮีโร่และหมูป่าเท่ากับ $\lfloor \text{damage} \times 0.10 \rfloor$ หน่วย
6. **Test Case 1.6: RO Falconer LUK Proc, INT/M.ATK Main Damage & Razor Gust Blind**
   - *เงื่อนไข*: เปรียบเทียบบิลด์สายนก INT/LUK (`int = 80, luk = 100, dex = 20`) กับสายธนู (`int = 1, luk = 20, dex = 80`) บนเป้าหมายที่มี `def = 200, mdef = 0.4, flee = 200`, และเหยี่ยวร่าย Blitz Beat ครั้งที่ 3 (`acts = 3`) โดยมีโหนด `bm_h2` (Steel Crow) และ `bm_h3`
   - *ผลที่คาดหวัง*:
     - โอกาสออก Blitz Beat ของสาย LUK 100 สูงกว่าสาย LUK 20 ตามสูตร `min(cap, 0.05 + 0.004 * luk + j2HawkChance)`
     - ดาเมจต่อฮิตของสาย INT 80 สูงกว่าสาย DEX 80 อย่างมีนัยสำคัญตามน้ำหนัก `FALCON_MIX` (`0.85 * matk + 0.15 * atk + j2HawkIntAdd * int`)
     - ทุกฮิตเป็น `sureHit = true` และ `pierce = 1` ข้ามทั้ง `flee`, `def` และ `mdef`
     - เป้าหมายที่โดนติด 🏷️ Prey Mark (ความแรงเพิ่มจาก `bm_h2`) และติดสถานะ 🙈 Blind นาน 2 เทิร์น (Hit -20)
7. **Test Case 1.7: Hawk Apex Spotter Wolf Rally & Blitz Storm (`bm_t4_hawk`)**
   - *เงื่อนไข*: เหยี่ยวแปะ Mark ลงบนเป้าหมายใหม่สำเร็จ, มี `bm_h4` ★ และ Talent `bm_t4_hawk` Rank 2
   - *ผลที่คาดหวัง*:
     - ฟังก์ชัน `c.rally('wolf')` ทำงาน เกจความเร็วของหมาป่ากลายเป็น $100$ ทันที
     - จำนวนฮิต Blitz Beat ขยายเพิ่ม $+2$ ฮิต (ทั้งขั้นต่ำและสูงสุด) และสามารถติด Falcon Crit (x1.5) บนเป้าที่ติด 🏷️ Mark ได้ด้วยอัตรา `0.5 * heroCrit`
8. **Test Case 1.8: Tri-Beast Harmony Chain**
   - *เงื่อนไข*: มีโหนด `bm_k4` ★, เหยี่ยวแปะ Mark บนเป้าหมาย, และหมาป่าเข้ากัดเป้าหมายนั้น
