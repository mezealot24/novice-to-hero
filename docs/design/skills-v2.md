## 1. กฎกลาง

### 1.1 สูตรดาเมจ

- **กายภาพ** (เหมือนเดิม): `ATK × (minPct–1) × ตัวคูณ` ต้องผ่าน Hit/Flee และโดน DEF · คริด้วย crit
- **เวท** (ใหม่): `Pm × (0.9–1.1) × ตัวคูณ` โดย `Pm = 0.7 × M.ATK + 0.3 × P.ATK` · ไม่พลาด · ไม่โดน DEF (มอนไม่มี M.DEF) · คริด้วย spellCrit
  - ใช้แทน `st.matk` ทุกจุดที่เป็นเวทของฮีโร่: `roll(magic)`, ไฟลุก stack, บาเรียจอมเวท, หอกแสง, relic ไฟโลกันตร์/สายฟ้าพิโรธ (เดิมใช้ max(ATK, M.ATK))
- **DoT** (ไฟลุก, พิษจากพร): โตตาม Pm · พิษของโจรยังใช้สูตรของเธรดโจร (ไม่แตะ)

ตัวอย่าง Pm ที่ Lv20 (ประมาณ): นักดาบ ATK ~120 / M.ATK ~10 → **43** · จอมเวท M.ATK ~110 / ATK ~15 → **82** · นักบวช M.ATK ~80 / ATK ~40 → **68**

### 1.2 ตัวจุดชนวน (Trigger) 12 แบบ

| id | ชื่อในเกม | จุดใน BattleScene |
|---|---|---|
| `turn` | ทุกเทิร์น | ต้นเทิร์นฮีโร่ (ที่เดียวกับ Lightning Bolt เดิม) |
| `every2` | ทุก 2 เทิร์น | ต้นเทิร์นฮีโร่ เมื่อ fightTurns เป็นเลขคู่ |
| `fightStart` | เริ่มไฟต์ | ต้นไฟต์ทุกห้อง (ที่เดียวกับ aegis / หอกเปิดศึก) |
| `basic` | ตีธรรมดา (มีโอกาส) | หลังตีปกติ 1 ครั้ง (ไม่นับคอมโบ) |
| `hits` | ฮิตครบ N | ตัวนับฮิตต่อไฟต์: ตีปกติ + คอมโบ + D.Strike (ไม่นับสกิล/พร กันวนลูป) |
| `ult` | ใช้ท่าไม้ตาย | หลัง Ult ร่ายเสร็จ |
| `skill1` | ใช้ทักษะ 1 | หลังสกิลออโต้ร่าย |
| `counter` | สวนกลับ | หลังสวนกลับ |
| `hurt` | โดนตี (มีโอกาส) | หลังโดนมอนตีเข้า (ไม่นับ DoT) |
| `dodge` | หลบได้ | หลังหลบ (Flee / หลบแน่นอน) |
| `lowHp` | HP ต่ำกว่า 30% ครั้งแรก | ครั้งเดียวต่อไฟต์ |
| `kill` | ล้มศัตรู | ทุกครั้งที่มอนตาย |

### 1.3 เอฟเฟกต์ (Effect) 9 ตัว

| id | ชื่อ | ทำอะไร | ชนิด |
|---|---|---|---|
| `zap` | ⚡ สายฟ้า | 0.3x Pm เป้าสุ่ม 1 ตัว | เวท |
| `fireball` | 🔥 ลูกไฟ | 1.0x Pm เป้าสุ่ม + ไฟลุก 1 stack | เวท |
| `firewave` | 🔥 คลื่นไฟ | 0.5x Pm ทุกตัว + ไฟลุก 1 stack | เวท |
| `icespike` | ❄️ หนามน้ำแข็ง | 0.5x Pm เป้าสุ่ม + **เย็น** 2 เทิร์น (มอนช้าลง 40%) · มอนธรรมดาที่เย็นอยู่ มีโอกาส 10% แช่แข็ง (ข้ามเทิร์น) | เวท |
| `spear` | ✨ หอกแสง | +1 หอก (ระบบหอกเดิม: เล่มละ 0.3x Pm ใส่ทุกตัว ยิงต้นเทิร์น สูงสุด 8) | เวท |
| `poison` | ☠️ พิษ | +N stack (ระบบพิษเดิม) | สถานะ |
| `shield` | 🛡️ โล่ | โล่ % HP สูงสุด | – |
| `heal` | 💚 ฟื้น | ฟื้น % HP สูงสุด | – |
| `res` | 💢 พลัง | +Mana/Energy/Rage | – |

**ไฟลุก** (รวมสองระบบไฟเดิมเป็นอันเดียว): stack ละ **0.12x Pm** ต่อเทิร์นมอน · อยู่ 3 เทิร์น (ติดใหม่ = รีเซ็ต) · สูงสุด 10 stack · ใช้ระบบ `burnStacks` ของ Ult ไฟจอมเวท และถอด `burnDps` (6 ดาเมจคงที่) ทิ้ง

### 1.4 กติกาการเสนอพร (เลเวลอัป)

- ยังเป็น **4 ตัวเลือก 1 คอลัมน์** (v48): 3 ใบสุ่มจากทุกสาย + 1 ใบทั่วไป · 60% มี 1 ช่องเอนไปสายที่มีอยู่แล้ว
- **"+" (เลือกซ้ำ)**: พรที่มีแล้วและยังไม่เต็ม จะโผล่เป็น "ชื่อ+" ในสุ่มได้ (นับเป็นใบของสายนั้น) · ทุกใบมี **2 ขั้น** (ฐาน → +) เว้นที่เขียนไว้
- **พรส้ม (ตำนาน)**: แต่ละช่องมีโอกาส `legendChance` (เดิม 3% + LUK สูงสุด 10%) **ปรับเป็น 6% + LUK สูงสุด 15%** เพราะตอนนี้ต้องมีพรฐานของสายนั้นก่อนถึงจะออก (ไม่มีพรสายไหนเลย = ไม่มีส้ม)
- ✦ ตำนาน x2 แบบเดิม **ถอด**
- ตัวกรองเดิมยังอยู่: จอมเวทไม่ได้พรติดตีปกติ (พิษติดตี, ดูดเลือด) · ธาตุของรอบจอมเวทยังกรองสาย (⚡ ตัด 🔥, 🔥 ตัด ⚡, ❄️ ได้ทั้งคู่) · พรติดตั้งแล้วใช้ไม่ได้ = ไม่โผล่
- จอมเวทจ่าย Mana ให้พรเวทเหมือนเดิม (สายฟ้า 2/ฮิต, ลูกไฟ 8) **ตุ๊กตาตัดสินแทนไปก่อน** เพราะจอมเวทมี Mana ล้นตอนไม่มีพรอื่นใช้ (เปลี่ยนได้)

## 2. พรธรรมดา (Common) — 9 สาย 51 ใบ

รูปแบบ: `ชื่อ` — ขั้นฐาน / **ขั้น +** · (ของเดิม = id เดิมที่ถูกแทน)

### ⚡ สายฟ้า (storm) 5 ใบ
1. **ฟ้าคำราม** `turn → zap` — ทุกเทิร์นผ่า 3 ครั้ง / **5 ครั้ง** (แทน stm1 Lightning Bolt Lv1–5, stm2)
2. **ฟ้าเปิดศึก** `fightStart → zap` — เริ่มไฟต์ผ่า 4 ครั้ง / **7 ครั้ง**
3. **ฟ้าตามฮิต** `hits → zap` — ทุก 4 ฮิตผ่า 1 ครั้ง / **ทุก 3 ฮิต**
4. **ท่าไม้ตายเรียกฟ้า** `ult → zap` — ใช้ Ult แล้วผ่า 3 ครั้ง / **5 ครั้ง**
5. **อาวุธอสนี** `basic → zap` — ตีธรรมดา 25% ผ่า 2 ครั้ง / **40%**

### 🔥 ไฟ (fire) 6 ใบ
1. **ลูกไฟ** `hits → fireball` — ทุกตีที่ 3 ยิงลูกไฟ / **ทุกตีที่ 2** (แทน fir1, fir3) · นับเฉพาะตีปกติ (เหมือนเดิม)
2. **วงไฟหมุน** `turn → fireball` — ทุกเทิร์นลูกไฟ 1 ลูก / **2 ลูก**
3. **ฝนไฟ** `fightStart → firewave` — เริ่มไฟต์ คลื่นไฟ 1 ระลอก + ไฟลุก 2 stack / **3 stack**
4. **เกราะเพลิง** `hurt → fireball` — โดนตี 30% ยิงลูกไฟใส่ตัวที่ตี / **45%**
5. **ท่าไม้ตายเพลิง** `ult → firewave` — ใช้ Ult แล้วคลื่นไฟ 2 ระลอก / **3 ระลอก**
6. **เชื้อเพลิง** (mod) — ตีศัตรูที่ติดไฟแรงขึ้น +15% / **+25%** (แทน fir2 เผาไหม้ที่เป็น 6 คงที่)

### ❄️ น้ำแข็ง (ice) 6 ใบ — **สายใหม่**
1. **คมน้ำแข็ง** `basic → icespike` — ตีธรรมดา 25% เรียกหนาม / **40%**
2. **หนามตามฮิต** `hits → icespike` — ทุก 5 ฮิต / **ทุก 4 ฮิต**
3. **ลมหนาว** `every2 → icespike(ทุกตัว 0.4x)` — ทุก 2 เทิร์น หนามใส่ทุกตัว / **ทุกเทิร์น**
4. **ท่าไม้ตายเหมันต์** `ult → icespike(ทุกตัว 0.6x)` — ใช้ Ult แล้วหนามทุกตัว / **+ ตัวที่เย็นอยู่แช่แข็งแน่นอน (ไม่ใช่บอส/มินิ)**
5. **เปราะน้ำแข็ง** (mod) — ศัตรูที่เย็นอยู่รับดาเมจ +15% / **+25%** (ไม่ซ้อนกับโหนดใยจอมเวท "เปราะ" ใช้ค่าสูงกว่า)
6. **กัดเย็น** (mod) — ศัตรูที่เย็นอยู่ตีเบาลง 15% / **25%**

### ✨ แสง (holy) 6 ใบ
1. **หอกรุ่งอรุณ** `fightStart → spear` — เริ่มไฟต์ได้หอก 3 เล่ม / **5 เล่ม**
2. **หอกรายเทิร์น** `every2 → spear` — ทุก 2 เทิร์น 1 เล่ม / **ทุกเทิร์น**
3. **หอกสวนกลับ** `counter → spear` — สวนกลับแล้วได้หอก 1 / **2**
4. **หอกท่าไม้ตาย** `ult → spear` — ใช้ Ult แล้วได้หอก 2 / **3** (นักบวชได้ 2 อยู่แล้ว ซ้อนได้)
5. **หอกคุ้มกาย** (mod) — หอกแต่ละเล่ม 20% ได้โล่ 3% HP / **30%**
6. **แสงอุ่น** (mod) — ฮีลแรง +20% / **+35%** (แทน hol1)

### ☠️ พิษ (venom) 5 ใบ
1. **เคลือบพิษ** (mod) — ทุกฮิตกายภาพติดพิษ 1 stack / **2 stack** (แทน ven1, ven3)
2. **พิษเข้มข้น** (mod) — พิษแรง +2 ต่อ stack / **+4** (แทน ven2)
3. **นักปรุงยา** (mod) — ตีศัตรูที่ติดพิษแรงขึ้น +15% / **+25%**
4. **ท่าไม้ตายพิษ** `ult → poison` — ใช้ Ult แล้วศัตรูทุกตัวติดพิษ 3 / **5 stack**
5. **หนามพิษ** `hurt(100%) → poison` — โดนตีแล้วคนตีติดพิษ 2 / **3 stack**

### 🛡️ ป้องกัน (guard) 6 ใบ
1. **โล่เปิดศึก** `fightStart → shield` — โล่ 10% HP / **15%**
2. **โล่ท่าไม้ตาย** `ult → shield` — โล่ 10% / **15%**
3. **โล่ตีธรรมดา** `basic → shield` — 15% ได้โล่ 4% / **25%**
4. **โล่คับขัน** `lowHp → shield` — โล่ 25% / **35%**
5. **แกร่ง** (mod) — รับดาเมจน้อยลง 10% / **15%** (แทน grd2 โล่ไม้)
6. **หนังหนา** (mod) — HP สูงสุด +50 / **+90** (แทน grd1)

### 💚 ชีวิต (life) 6 ใบ
1. **ลมหายใจ** (mod) — ฟื้น HP 1.5%/เทิร์น / **2.5%** (แทน grd3, hol3)
2. **ฮิตฟื้นกาย** `hits → heal` — ทุก 4 ฮิตฟื้น 3% / **ทุก 3 ฮิต ฟื้น 4%**
3. **ฟื้นยามคับขัน** `lowHp → heal` — ฟื้น 8%/เทิร์น 3 เทิร์น / **12%**
4. **ท่าไม้ตายฟื้นกาย** `ult → heal` — ฟื้น 5% / **8%**
5. **เก็บเกี่ยว** `kill → heal` — ล้มศัตรูฟื้น 3% / **5%**
6. **ดูดเลือด** (mod) — ตีปกติ+คอมโบดูดเลือด 6% / **10%** (แทน bld1 · กฎเดิม: เพดาน 40%, ไม่ดูดจากสกิล/พร)

### ⚔️ อาวุธ (weapon) 7 ใบ — ตัวขยายตีธรรมดา
1. **ตาเหยี่ยว** — คริ +12% / **+20%** (แทน crit1, crit3)
2. **จุดตาย** — ดาเมจคริ +40% / **+70%** (แทน crit2)
3. **ฟันรัว** — คอมโบ +10% / **+15%** (แทน spd4 · เพดาน 50% เดิม)
4. **ท่าสวน** — สวนกลับ +12% / **+18%** (แทน grd4)
5. **สวนหนัก** — ดาเมจสวนกลับ +25% / **+45%**
6. **ฝึกตี** — ตีปกติแรง +20% / **+35%** (แทน bld2 คลั่งเลือด)
7. **มือไว** — ความเร็วเทิร์น +12% / **+20%** (แทน spd1, spd2)

### 💢 สมาธิ (focus) 4 ใบ — ท่าไม้ตาย / ทรัพยากร
1. **สมาธินิ่ง** — Ult คูลดาวน์ −1 เทิร์น (ไม่มี + · มีได้ใบเดียว) (แทน spd3)
2. **บดกระดูก** — Ult แรง +40% / **+70%** (แทน bld3 ที่เป็น x2 แรงเกิน)
3. **ปลุกพลัง** `fightStart → res` — เริ่มไฟต์ resource +25 / **+45**
4. **ภาวนา** (mod) — ฟื้น resource +2/เทิร์น / **+4**

### ⭐ พรทั่วไป (ช่องที่ 4 เสมอ) — คงเดิม 8 ใบ

## 4. 🔴 พรเทพ (Mythic)

**ได้จากไหน**: ชนะมินิบอส (ดัน 3+, หอคอย gauntlet) → เลือก 1 จาก 3 แบบเดิม (2 ตัวประจำมินิบอส + 1 สุ่มจากกองเทพ) · มีได้ **1 ใบต่อรอบ** เหมือน relic เดิม · ระบบ `offerRelic` เดิมใช้ต่อ แค่เพิ่มของในกอง

### 4.1 relic เดิม 12 ตัว → ย้ายเป็นพรเทพ (ไม่แก้กลไก)
ตรีพลัง · สายฟ้าพิโรธ · ยุคน้ำแข็ง · ไฟโลกันตร์ · สัญญาเลือด (= ร่าง "แวมไพร์") · ปัดป้องไร้ที่ติ · เร่งเวลา · เก็บเกี่ยววิญญาณ · กายบริสุทธิ์ · เพชฌฆาต · โล่อมตะ · เกราะหนามอเวจี
- ⚠️ สายฟ้าพิโรธ / ไฟโลกันตร์ เปลี่ยนจาก max(ATK, M.ATK) เป็น Pm ตามกฎข้อ 1 → สายกายภาพจะเบาลง **เสนอชดเชย**: สายฟ้าพิโรธ 0.75x → 1.1x, ไฟโลกันตร์ dmgPerStack x1.4 (เพราะเป็นของเทพ ควรรู้สึกแรง)

### 4.2 ร่างสลับสไตล์ (ใหม่ 4 ตัว) — เปลี่ยนวิธีเล่นทั้งตัว
| ชื่อ | ได้ | เสีย |
|---|---|---|
| 🐺 **ร่างหมาป่า** | ดาเมจคอมโบ + สวนกลับ +60% · คอมโบ +10% | ดาเมจทักษะ 1/2 + Ult −40% |
| 🧙 **จอมขมังเวท** | ดาเมจทักษะ 1/2 + Ult +60% | โอกาสคอมโบ + สวนกลับ −50% (ครึ่งหนึ่ง) |
| 👹 **ร่างอสุรา** | คริ +20% · ดาเมจคริ +60% | ฟื้น resource ต่อเทิร์น −50% |
| 😈 **ราชินีธาตุ** | ดาเมจธาตุ (⚡🔥❄️✨☠️ ทั้งพรและ DoT) +60% | ตีปกติ −50% |

### 4.3 ร่างแปลง (ใหม่ 3 ตัว) — ต้องมีเอฟเฟกต์ฐานก่อน ถึงจะโผล่
| ชื่อ | ต้องมี | ผล |
|---|---|---|
| ⚡ **อสนีเทพ** | พร ⚡ ใดก็ได้ | สายฟ้าทุกครั้ง 20% กลายเป็นฟ้าผ่าใหญ่ x3 + ระเบิดใส่ตัวข้างๆ 0.5x |
| ✨ **หอกเวท** | พร ✨ ใดก็ได้ | หอกแสงแรง x2.5 และแต่ละเล่มปล่อยคลื่นไฟ |
| 💔 **แก้วร้าว** | — | HP < 30%: ดาเมจ +60% · รับดาเมจ +30% · ล้มศัตรูฟื้น 5% |

กองเทพรวม = 12 + 4 + 3 = **19 ใบ**

## 7. ข้อเสนอโครงสร้างโค้ด (ให้ coordinator ใช้วาง architecture)

```ts
// src/data/perks-v2.ts (ข้อมูลล้วน)
type Line = 'storm' | 'fire' | 'ice' | 'holy' | 'venom' | 'guard' | 'life' | 'weapon' | 'focus' | 'common'
type Rarity = 'common' | 'legend' | 'mythic' | 'immortal'
type Trigger = 'turn' | 'every2' | 'fightStart' | 'basic' | 'hits' | 'ult' | 'skill1' | 'counter' | 'hurt' | 'dodge' | 'lowHp' | 'kill'
type Effect = 'zap' | 'fireball' | 'firewave' | 'icespike' | 'spear' | 'poison' | 'shield' | 'heal' | 'res'
interface Proc { on: Trigger; n?: number[]; chance?: number[]; fx: Effect; count?: number[]; pow?: number[]; aoe?: boolean; stacks?: number[] }
interface PerkV2 {
  id: string; line: Line; rarity: Rarity; icon: string; name: string
  desc: (lv: number) => string; maxLv: 1 | 2
  proc?: Proc            // ค่าใน array = [ขั้นฐาน, ขั้น +]
  mod?: (lv: number) => Partial<Stats>
  needs?: Line | string  // legend/transform: ต้องมีสายหรือพรนี้ก่อน
}
```

- `src/scenes/battle-procs.ts`: `fireProcs(trigger, ctx)` วนพรที่มี proc ตรง trigger → เรียก effect 1 ฟังก์ชันต่อเอฟเฟกต์ · ยิงพร้อมกันเป็นชุด รอ anim ครั้งเดียว (กันเทิร์นยืด)
- BattleScene: เพิ่ม hook 12 จุดตาม 1.2 (ส่วนใหญ่มีที่อยู่แล้ว) + `magicPower()` แทน `st.matk` + ตัวนับ `fightHits`
- ดาเมจต้องติดป้ายที่มา `src: 'basic' | 'combo' | 'counter' | 's1' | 's2' | 'ult' | 'proc' | 'dot'` เพื่อให้ร่างสลับสไตล์คูณถูกที่ (Stats ใหม่: `comboDmg`, `counterDmg`, `skillDmg`, `basicDmg`, `elemDmg`)
- `offerPerks()` เขียนใหม่ตาม 1.4 · `offerRelic()` ใช้กองเทพใหม่ · อีเวนต์อมตะ 3 ตัวไปอยู่ `data/events.ts`
- bot: `PERK=id[,id]` บังคับพร, `MYTHIC=id` (แทน `RELIC=`)
