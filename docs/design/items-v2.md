# ระบบไอเทม v2 (2026-11-03)

โค้ด: `game/src/data/meta.ts` (ITEMS, itemStatLine, canWear, itemUnlocked, gearBase)

## กติกา
- ไอเทมให้ได้ 2 แบบ: **ค่าสถานะหลัก** (`base`: STR/VIT/WIS/DEX/INT/LUK/AGI ผ่านสูตร stat spec v1 เหมือนลงแต้ม) + **ค่าย่อย** (`mod`: Hit, Flee, Counter, Combo, ดูดเลือด, Mana Shield ฯลฯ)
- 1 ช่อง = 1 ชิ้น (อาวุธ / เกราะ / เครื่องประดับ) ไม่มีการซ้อน ไม่มีของขายด้วยเงินจริง
- `jobs` = อาชีพที่ใส่ได้ (ไม่มี = ทุกอาชีพ) · ใส่ของผิดอาชีพค้างไว้ = ไม่ได้ค่าพลัง (เช่นตอนเปลี่ยนอาชีพใหม่)
- `req`: `job` ขายหลังเปลี่ยนอาชีพ · `d2` ขายหลังล้มบอสป่าหมาป่าเงา
- คำอธิบายตัวเลขสร้างอัตโนมัติจากข้อมูล (ไม่มีทางพิมพ์ไม่ตรง)
- Item id = save data ห้ามเปลี่ยนชื่อ/ลบ

## ค่าใหม่ 2 ตัว
- `dodgeHeal` หลบได้ (ทุกแบบ) = ฟื้น HP x% ของ HP สูงสุด (สายโจร) cap 8%
- `waveShield` ต้นทุกเวฟได้โล่ x% ของ HP สูงสุด (เติมให้เต็ม ไม่ซ้อน) (สายนักดาบ/นักบวช) cap 20%
- cap เพิ่ม: ดูดเลือด 40%, Mana Shield 70%, คริ→โล่ 40%

## ของประจำคลาส (ตามสไตล์เอาตัวรอด)
| อาชีพ | อาวุธ 2 ทาง (520-560) | อาวุธดัน 2 (1100) | เกราะ |
|---|---|---|---|
| นักดาบ | ดาบกระหายเลือด (ดูดเลือด) / ดาบผู้พิทักษ์ (สวนกลับ) | ขวานคลั่งศึก | เกราะหนามเลือด, เกราะเหล็กหนัก (+นักบวช) |
| นักธนู | ธนูพราน (Hit/คริ) / ธนูเหยี่ยวลม (คอมโบ, คริ→โล่) | ธนูดาวตก | ผ้าคลุมตาเหยี่ยว, เสื้อนักล่า (+โจร) |
| จอมเวท | คทาอัญมณี (M.ATK) / คทาวงเวทป้องกัน (Mana Shield) | คทาจอมปราชญ์ | เสื้อคลุมรูน, เสื้อคลุมปราชญ์ (+นักบวช) |
| นักบวช | กระบองศักดิ์สิทธิ์ (ฮีล) / คัมภีร์แสง (โล่, regen) | ค้อนตะวัน (โล่ต้นเวฟ) | อาภรณ์แสง |
| โจร | กริชพิษ (พิษ) / มีดเงา (หลบ→ฟื้น) | เขี้ยวงูคู่ | ชุดจอมโจรราตรี |

เครื่องประดับ ทุกอาชีพใส่ได้ เลือกตามค่าที่ build ขาด: คริ/ดรอป, Hit, regen, ต้านทาน, Flee+หลบฟื้น, สวนกลับ, ฮีล/โล่, คอมโบ, Mana, ดูดเลือด, ของดัน 2 ทุกค่า +2
