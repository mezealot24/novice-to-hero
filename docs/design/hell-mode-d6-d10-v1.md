## 0. สรุปสั้น (so what)

- ความยากขั้นใหม่**เหนือ 🔥 โหมดยาก** สำหรับดัน 6–10 (ไม่มีใน D1–D5)
- **ปลดล็อกทีละดัน:** เคลียร์ดันนั้นใน 🔥 โหมดยาก 1 ครั้ง → ปุ่ม 😈 ขึ้นข้างปุ่ม 🔥 ในเมือง
- **ระบบเดิมทั้งหมด reuse:** run = โหมดยาก (แต้มสถานะ +50%, สกิลบอส, corruption) + มอนทุกตัวผ่าน `hellify()` (ระบบเดียวกับ Hell ในหอคอยชั้น 25+) · ไม่มีภาพใหม่ (tint แดงเข้ม)
- ไม่มีเพชร ไม่มีของสุ่มใหม่ (ยูนีคใช้ตารางเดิม แค่โอกาสสูงขึ้น) → ไม่กระทบ odds page / no-P2W
