## ปัญหาเดิม

- การ์ดสายสมาธิอ่อน / ใช้ได้บางอาชีพ (`needsRes`)

## กฎร่าย (Mage + Sage)
| สกิล | ร่าย? | หมายเหตุ |
|---|---|---|
| Skill 1 ลูกไฟระเบิด | ร่าย 1 เทิร์น | ร่ายเสร็จแรง `fireMul` 1.8x (เดิม 0.9x ทุกเทิร์น → ลงทุก 2 เทิร์น เฉลี่ยเท่าเดิม) | · **v85: กลับเป็นร่ายทันที**
| Ult เวทธาตุ (Mage เท่านั้น) | ร่าย 1 เทิร์น | แรง ×`ultMul` 1.3 (ดาเมจ + บาเรีย) |
| Magic Bolt (ตีปกติ) | ทันที | โดน → Mana +`boltMana` 6 |
| Skill 2 / การ์ด / Sage Dispell | ทันที | — |
| Wizard (Storm Gust / ult) | ระบบเดิม | ปล่อยฟรี (ไม่กินเทิร์น) · ไม่แตก · ดาเมจเข้า +15% ตอนร่าย |

- หัก Mana + คูลดาวน์ตอนเริ่มร่าย · ปล่อยต้นเทิร์นถัดไป (ก่อนเช็กใบ้)
- **Mage / Sage: เทิร์นที่ปล่อย = action ของเทิร์นนั้น** (`castUsesTurn`) — Skill 2, Mana regen, การ์ดรายเทิร์น, Endow ยังทำงาน แต่ไม่มี Skill 1 / ult / ตีปกติ
- Wizard ปล่อยฟรี แล้วทำ action ปกติต่อได้ (ข้อได้เปรียบของ Wizard)
- ult ทุกสาย Mage คิดดาเมจจาก `hitPow` (รวม `ultAmp` / บดกระดูก) · บาเรียยังคิดจาก `pow`
- เวฟใหม่ = ล้างคิวร่าย (Mana หาย เหมือน Wizard)
- การ์ดหลังใช้ ult / Zen ทำงานตอนเวทลงจริง (Wizard ด้วย)

## ร่ายแตก
- `breakChance = max(0, 0.45 − 0.012×DEX − tenacity)` (DEX รวม)
  - DEX 0 = 45% · DEX 30 = 9% · DEX 38+ = 0%
- เช็กทุกฮิตที่ **ทะลุโล่ทุกชั้นถึง HP**: `hurtHero` · `trueHurt` · `dotHurt`
- โล่ / Kyrie / Mana Shield รับหมด → ไม่แตก
- กันแตกแน่นอน: Wizard · 🧘 Poise
- แตก → ล้างคิว · Mana ที่จ่ายหาย · ult คูลดาวน์เหลือ `brokenUltCd` 2 · "💔 ร่ายแตก!"

## v85 ผ่อนร่ายแตก (playtest 2026-11-06)
