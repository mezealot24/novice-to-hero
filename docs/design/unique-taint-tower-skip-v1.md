## 1. 🗼 ข้ามชั้นหอคอย (v87)

### 1.1 กติกา
| หัวข้อ | ค่า |
|---|---|
| checkpoint | ทุก `TOWER.skipEvery = 10` ชั้น |
| checkpoint สูงสุด | `floor(bestFloor / 10) * 10` (best 34 → 30 · best 29 → 20 · best < 10 → ข้ามไม่ได้) |
| เลือกได้ | checkpoint S ใดก็ได้ตั้งแต่ 10 ถึงสูงสุด · เริ่มที่ S ⇒ ต่อสู้ครั้งแรกที่ชั้น **S+1** |
| ราคา | `gems = S * TOWER.skipGems` (`skipGems = 1`) · เช็คว่าพอ · **หักตอนรันเริ่ม** (ไม่ใช่ตอนกดเลือก) |
| ไต่ใหม่ (retry) | จ่ายใหม่ทุกครั้งที่รันเริ่ม · ถ้าเพชรไม่พอตอน retry → เริ่มชั้น 1 แทน + ข้อความบอก |
| ชั้นที่ข้าม | **ไม่ได้อะไร**: ไม่มี zeny / วัตถุดิบ / เพชร first-time · ไม่นับว่าเคลียร์ |
| `bestFloor` | ขึ้นเมื่อชนะ "ของจริง" เท่านั้น (ต้องผ่านชั้น > best) · ข้าม ≠ สถิติ |

กัน 3 ชั้นพร้อมกัน (belt and braces) ใน `towerFloorLoot`/`reward`:
1. `bank` มีแต่ชั้นที่เคลียร์จริง (BattleScene.floorCleared) — ชั้น ≤ S ไม่เคยถูกเรียก
2. `RunResult.from = S` → `reward()` ตัด `cleared` ที่ ≤ S ทิ้งก่อนคิดเพชร first-time / bestFloor
3. test `tests/tower-skip.test.ts` ยืนยัน

### 1.2 Catch-up power
ในหอคอยฮีโร่โตตามเลเวลในรัน (perk pick) + ถือพรเทพ (relic) จากการดวล (gauntlet ชั้น 10, 20, ...) — เริ่มเย็นที่ชั้น 31 = ตาย

| หัวข้อ | ค่า |
|---|---|
| บันทึก | ครั้งแรกที่รันผ่าน checkpoint f (ชั้น 10, 20, ...) เก็บ `cp[f] = { lv, relic? }` ลง `save.modes.tower` (เก็บ **level สูงสุด** ข้ามทุกรัน · `relic: true` ถ้ามีรันไหนถือพรเทพ · Q 2026-11-07) |
| ตอนข้าม | เริ่มรันที่ `level = lv` · `pendingLevels = lv - 1` → เลือกการ์ด (perk) ครบทุกใบก่อนสู้ชั้นแรก |
| พรเทพ | ถ้าบันทึก `relic: true` → เปิดหน้าเลือกพรเทพ 1 ครั้งหลังเลือกการ์ดเสร็จ (ใช้ `offerRelic` เดิม, ชุดตัวเลือกต่างจากของจริงนิดหน่อยเพราะไม่มีมินิบอสให้อิง) |
| ไม่มีบันทึก (เซฟเก่า) | ประมาณ: `lv = clamp(1 + round(S * TOWER.skipLvPerFloor), 1, TOWER.skipLvMax)` · `skipLvPerFloor = 0.5` · `skipLvMax = 60` · relic = true (ชั้น 10 มี gauntlet เสมอ) |
| ข้ามอีเวนต์ | เหตุการณ์ระหว่างชั้น (ทุก 3 ชั้น) ของชั้นที่ข้ามไม่ถูกเล่นย้อน (ไม่ได้ผลจากอีเวนต์) |
| ข้ามกฎหอคอย | affix ของชั้นที่ข้ามเริ่มทำงานทันทีตามชั้นปลายทาง (`affixesAt`) — ไม่ต้องทำอะไร |

## 3. 🌑 Taint — กดคำสาปใส่ของ (v89)

### 3.1 ไอเดีย
ลุ้นครั้งเดียวที่โรงตีเหล็ก กับของที่ตีบวกได้ (รวมยูนีค) และยังไม่ติดคำสาป → ผลแบบ PoE "Corrupt" แล้ว **ล็อกชิ้นนั้นถาวร**

### 3.2 ต้นทุน
| ค่า | ตัวเลข |
|---|---|
| zeny | `TAINT.zeny = 3000` (ราคาเดียวทุกชิ้น — zeny sink ล้วน) |
| วัตถุดิบ | `TAINT.crystals = 2` x **🔻 ผลึกโลกันตร์** (`x_taint`) |
| ได้ผลึกจาก | บอสสุดท้ายของดัน **D6 ขึ้นไป** (โหมด `dungeon`/`hard`) `MAT_RULES.taintBoss = 1` ต่อบอส (โหมดยากคูณ `HARD.mats` ตามวัตถุดิบอื่น) |
| เงื่อนไขของ | `refinable(it)` · ยังไม่ติดคำสาป · **ไม่แตก** (ซ่อมก่อน — ตัดสินใจเอง) |

### 3.3 ผลลัพธ์ (เท่ากัน 25% — `TAINT.odds`)
| # | ผล | รายละเอียด |
|---|---|---|
| 1 | 😐 ไม่เกิดอะไร | จ่ายค่าฟรี ของถูกล็อก |
| 2 | ✨ ทองทั้งชิ้น | ทุกบรรทัดค่าพิเศษที่มี → gold (คูณ `REFINE.goldMul` = 1.5, บรรทัดที่เป็นทองอยู่แล้วคงเดิม) · **ถ้าไม่มีบรรทัดเลย:** ได้บรรทัดเล็ก (ช่อง +5) 1 บรรทัดที่เป็นทอง (ตัดสินใจเอง) |
| 3 | 💀 บรรทัดคำสาป | สุ่ม 1 จากพูล `CURSES` (ข้อดีแรง + ข้อเสีย) เก็บที่ `taint[id].curse` |
| 4 | 💥 พัง | เสียบรรทัดค่าพิเศษ 1 บรรทัดแบบสุ่ม · ไม่มีบรรทัด → ตีบวก −1 (ไม่ต่ำกว่า +0) |

### 3.5 ล็อกหลังติดคำสาป
| ห้าม | ที่บังคับ (pure rule ไม่ใช่แค่ UI) |
|---|---|
| ตีบวก | `tryRefine` → `{ ok:false, why:'tainted' }` |
| สุ่ม gacha / ล็อกบรรทัด | `reroll` → `null` |
| อัปขั้น | `upgradeGrade()` ใหม่ใน `refine.ts` → `'tainted'` (ForgeScene เรียกอันนี้แทนโค้ดเดิมที่แก้ `save` ตรง ๆ) |
| ติดคำสาปซ้ำ | `tryTaint` → `'tainted'` |
| **ยังทำได้** | ซ่อมของแตก (วัตถุดิบ / เพชร) · ใส่การ์ด · ใส่/ถอด |

UI: ปุ่มที่ห้ามจะดับ + ข้อความ "🌑 ติดคำสาปแล้ว: ล็อกตีบวก / สุ่ม / อัปขั้น"

### 3.6 Save (เพิ่มอย่างเดียว)
| field | ความหมาย |
|---|---|
| `taint?: Record<string, { kind: 'none' \| 'gold' \| 'curse' \| 'brick'; curse?: string }>` | item id → ผลที่ได้ (มี record = ติดแล้ว = ล็อก) |

- ผล `gold`/`brick` แก้ `refineLines` / `refine` ตรง ๆ (record แค่ล็อก)
- `forgetForge()` ล้าง `taint[id]` ตอนของออกจากกระเป๋า
- ค่าคำสาปประกอบเข้าไอเทมใน `meta.forged()` (ไม่ผ่านการคูณขั้น/บวก)

### 3.7 UI
- การ์ดแท็บ "⚒️ ตีบวก": ปุ่ม **🌑** เล็กข้างปุ่มตี → ป๊อปอัป: ต้นทุน + ตารางโอกาส + คำเตือน (ล็อกถาวร) → `confirm` → ผลลัพธ์ `confirm` อีกอัน
