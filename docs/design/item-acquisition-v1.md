# ระบบหาไอเทม + Craft + อัปเกรดขั้น — Design v1 (2026-11-03)

> อ้างอิง: วิกิอุปกรณ์ Capybara Go ที่คิวแนบมา (ไอเทม 5 ขั้น ปลดโบนัสทีละขั้น) · ใช้ชื่อและผลของเราเองทั้งหมด ไม่ลอกของเขา
> ต่อจาก: `design/items-v2.md` (ITEMS ใน meta.ts), `design/equipment-cards.md` (การ์ด v24), `design/equipment-screen-v1.md` (6 ช่อง กำลังทำอีกเธรด)

## 0. TL;DR (so what)
- ตอนนี้ไอเทม **มาจากร้านทางเดียว** → zeny พอแล้วซื้อจบ ฟาร์มดันเก่าไม่มีอะไรลุ้นนอกจากการ์ด
- หนูแนะนำเพิ่ม 3 อย่าง เรียงตามความสำคัญ:
  1. **วัตถุดิบจากมอน** (ดรอปบ่อย เห็นตัวเลขชัด แพ้ก็ได้เก็บ) — ดันละ 2 ชนิด
  2. **โรงตีเหล็ก (Craft)** ในเมือง: วัตถุดิบ + zeny → ของดัน (สำเร็จ 100% ไม่มีสุ่ม)
  3. **อัปเกรดขั้น 5 ระดับ** แบบ Capybara (ปลดโบนัสที่ขั้น 3 กับ 5) แต่ใช้ **วัตถุดิบ** แทนการรวมของซ้ำ 3 ชิ้น
  4. **ตีบวก +1~+10** แบบ RO (คิวเลือก): ใช้วัตถุดิบ + **ของร้านพื้นฐานเป็นเชื้อหลอม** · ตั้งแต่ +5 มีโอกาสพลาด → ของ **แตก** (ไม่หาย ไม่ลดบวก) ต้องซ่อมด้วยวัตถุดิบหรือเพชร
- ขั้น = ปลดโบนัส (ความสามารถใหม่) · ตีบวก = ตัวเลขดิบ (ลุ้นสนุก) → 2 ระบบทำหน้าที่ไม่ซ้ำกัน
- ร้านค้ายังอยู่ = ของพื้นฐาน + ของคลาส · ของดัน/ของช่องใหม่ (หมวก, มือรอง) = **Craft**
- ไม่มีกาชา ไม่มีขายวัตถุดิบ/โอกาสสำเร็จ/กันแตกด้วยเพชร · เพชรใช้ได้อย่างเดียวคือ **ซ่อมของแตก** (ซ่อมด้วยวัตถุดิบถูกกว่าเสมอ และเพชรหาฟรีได้)

## 1. แหล่งที่มาของไอเทม (ภาพรวม)

| แหล่ง | ได้อะไร | สุ่มไหม | สถานะ |
|---|---|---|---|
| 🏪 ร้านค้า (zeny) | ของพื้นฐาน + ของคลาส 520–560z + หมวก/มือรองพื้นฐาน | ไม่สุ่ม | มีแล้ว |
| 🃏 การ์ดมอน | การ์ดใส่ช่องอุปกรณ์ | สุ่ม + pity | LIVE v24 |
| 🧱 วัตถุดิบจากมอน | วัสดุ Craft / อัปเกรด | ดรอปบ่อย (ไม่ลุ้นเหนื่อย) | **ใหม่** |
| 🔨 โรงตีเหล็ก | ของดัน, ของช่องหมวก/มือรองระดับสูง | ไม่สุ่ม (100%) | **ใหม่** |
| 👑 บอสเคลียร์ครั้งแรก | ปลดสูตร Craft ของดันนั้น + วัตถุดิบบอส | ไม่สุ่ม | **ใหม่** |
| 📦 หีบระหว่างรอบ (อีเวนต์เดิม) | เพิ่มวัตถุดิบ 1–3 ชิ้นนอกจาก zeny | สุ่มเบาๆ | ต่อยอดของเดิม |
| 💀 ของหายากจากบอส (MVP drop) | ของ unique 1 ชิ้นต่อบอส ทำ Craft ไม่ได้ | สุ่ม + pity | เฟส 3 (ไม่ต้องรีบ) |

**ทำไมไม่ให้มอนดรอปอุปกรณ์ตรงๆ (แบบ Diablo/RO)?**
- เกมเราเก็บของแบบ **1 ไอดี = 1 ชิ้น** (`owned` เป็นลิสต์ไอดี) ดรอปซ้ำจะไม่มีความหมาย ต้องรื้อกระเป๋าใหม่ทั้งระบบ
- ดรอปของสุ่มเยอะ = กระเป๋ารก + ความรู้สึก "ลุ้นกาชา" ซึ่งขัดจุดยืนเรา
- วัตถุดิบ = ได้ทุกรอบ เห็นความคืบหน้า (12/15) → ADHD-friendly กว่า ไม่มีรอบไหน "เสียเปล่า"

## 2. วัตถุดิบ (Materials)

ดันละ 2 ชนิด: **ธรรมดา** (มอนทั่วไป) + **บอส** (บอสประจำดัน/มินิบอส)

| ดัน | 🧱 ธรรมดา | 💠 บอส |
|---|---|---|
| D1 ทุ่งเจลล็อป | เมือกใส | แกนเจลราชา |
| D2 ป่าหมาป่าเงา | ขนเงาจันทร์ | กรงเล็บจ่าฝูง |
| D3 ซากป้อมวีรชน | เศษเกราะสนิม | ตราผนึกอัศวิน |
| D4 บึงพิษมรกต | เกล็ดหนองมรกต | น้ำดีไฮดรา |
| D5 บัลลังก์อเวจี | ผงกระดูกอเวจี | ผลึกวิญญาณลิช |

**อัตราดรอป** (ปรับได้หลังรันบอท)
- มอนธรรมดา: **30%** ได้ 1 ชิ้น (ตอน build นับจริงแล้ว D1 มีมอนธรรมดาแค่ 13 ตัว/รอบ เลยขึ้นจาก 15%) → รอบ D1 ได้ ~4 ชิ้น + บอสอีก 3
- มินิบอส D3 / บอสย่อย D4–5: ได้แน่ 1 ชิ้นวัตถุดิบบอส
- บอสประจำดัน (ชนะ): ได้แน่ 2 ชิ้นวัตถุดิบบอส + 3 ชิ้นธรรมดา
- มอนที่ถูกเรียกออกมา (เจลล็อปจิ๋ว ฯลฯ) **ไม่ดรอป** เหมือนกฎการ์ด กันฟาร์มลูกสมุน
- **แพ้/กลับเมืองก็ได้เก็บ** ที่เก็บมาแล้ว (เหมือน zeny + การ์ด)
- LUK **ไม่**คูณอัตราวัตถุดิบ (LUK ช่วยการ์ด/เพชรอยู่แล้ว ไม่อยากให้สายดวงได้ทุกอย่าง)
- หีบอีเวนต์: หีบธรรมดา +1–3 ธรรมดา · หีบทอง +1 วัตถุดิบบอส
- โชว์ตอนดรอป: ตัวลอย `🧱 เมือกใส +1` (เล็กกว่าการ์ด ไม่ให้จอรก) + บรรทัดสรุปหน้าผลลัพธ์

## 3. โรงตีเหล็ก (Craft)

อาคารใหม่ในเมือง `🔨 โรงตีเหล็ก` 3 แท็บ: **สร้าง / อัปเกรด / หลอมคืน**

### 3.1 สร้าง (Craft)
- สูตร = วัตถุดิบ + zeny → ได้ของ **ขั้น 1** ทันที **สำเร็จ 100%** (ไม่มีสุ่มพัง)
- สูตรของดันไหน ปลดเมื่อ **ชนะบอสดันนั้นครั้งแรก** (ไม่ต้องลุ้นดรอปสูตร)
- โชว์สูตรที่ยังล็อกเป็นเงา + บอก "ล้มบอส X เพื่อปลด" → มีเป้าหมายให้เห็น
- ต้นทุนตัวอย่าง: ของดันชั้น n = ธรรมดา 8 + บอส 2 ของดันนั้น + zeny ~60% ของราคาร้านดันเดียวกัน

### 3.2 อัปเกรดขั้น (Grade) — หัวใจของระบบ
5 ขั้น สีกรอบไอคอนตามขั้น (ชื่อเราเอง ไม่ใช้ชื่อขั้นของ Capybara):

| ขั้น | ชื่อ | สี | ได้อะไร |
|---|---|---|---|
| 1 | ธรรมดา | ขาว | ค่าพลังพื้นฐาน |
| 2 | ขัดเงา | เขียว | ค่าพลังทั้งชิ้น +15% |
| 3 | ชำนาญ | ฟ้า | +30% และ **ปลดโบนัสพิเศษ 1** |
| 4 | ปรมาจารย์ | ม่วง | +45% และ **เพิ่มช่องการ์ด +1** (สูงสุด 2 ช่อง/ชิ้น) |
| 5 | ตำนาน | ส้มทอง | +60% และ **ปลดโบนัสพิเศษ 2** |

- "+x%" คูณทั้ง `base` และ `mod` ของไอเทม (ปัดเศษตามชนิดค่า) → สูตรเดียว ไม่ต้องเขียนตัวเลขทีละชิ้น
- **ขั้นสูงสุดตามแหล่ง** กันของร้านแซงของดัน:
  - ของร้านพื้นฐาน → สูงสุดขั้น 3 (ไม่มีโบนัสพิเศษ ได้แค่ % ขึ้น)
  - ของคลาสร้าน 520–560z → สูงสุดขั้น 4
  - ของ Craft / ของดัน → ถึงขั้น 5 ครบ
- อัปเกรด **สำเร็จ 100%** ไม่แตก ไม่ลดขั้น (ไม่ใช่ RO refine)
- เปลี่ยนอาชีพ/ใส่ผิดอาชีพ: ขั้นยังอยู่ แค่ไม่ได้ค่าพลัง (กฎ `wornItems` เดิม)

**ต้นทุนอัปเกรด** (วัตถุดิบของดันที่ของชิ้นนั้นมาจาก · ของร้านใช้ D1 หรือ D2 ตาม `req`)

| ขึ้นไปขั้น | 🧱 ธรรมดา | 💠 บอส | zeny |
|---|---|---|---|
| 2 | 3 | – | 100 |
| 3 | 6 | 1 | 250 |
| 4 | 10 | 2 | 500 |
| 5 | 15 | 4 | 1000 |
| **รวม 1→5** | **34** | **7** | **1850** |

- ประมาณ ~8 รอบ + ล้มบอส 4 ครั้ง ต่อของ 1 ชิ้นถึงตำนาน (จะรันบอทวัดจริงก่อนล็อกตัวเลข)
- zeny ยังสำคัญจนเลทเกม (เป็น zeny sink ที่ดี)

### 3.3 หลอมคืน (Dismantle)
- ของ Craft ที่ไม่ใช้แล้ว → ได้วัตถุดิบคืน **50%** ของที่ลงไปทั้งหมด (สร้าง + อัปเกรด)
- ของร้านยังขายได้ครึ่งราคาเหมือนเดิม + คืนวัตถุดิบอัปเกรด 50%
- การ์ดที่เสียบอยู่เด้งกลับกระเป๋าก่อนเสมอ (`unsocketAll` เดิม)

## 3.4 เทียบ 3 แบบอัปเกรด (คิวเลือก B + C ใช้คู่กัน)

| | A. รวมของซ้ำ (Capybara) | **B. อัปขั้นด้วยวัตถุดิบ (แนะนำ)** | C. ตีบวก +1~+10 (RO refine) |
|---|---|---|---|
| วิธี | ของชิ้นเดียวกัน 3 ชิ้น → ขั้นถัดไป | วัตถุดิบ + zeny → ขั้นถัดไป | แร่ + zeny ลุ้นสำเร็จ ขั้นสูงพลาดแล้วพัง |
| ต้องรื้อเซฟ | ต้อง (ของซ้ำหลายชิ้น) | ไม่ต้อง (เพิ่ม `grade`) | ไม่ต้อง (เพิ่ม `refine`) |
| ความรู้สึก | ต้องฟาร์มของซ้ำ = เหมือนกาชา | เห็นความคืบหน้าชัด ไม่มีเสียเปล่า | ลุ้นสนุก แต่หงุดหงิดตอนพัง |
| ปลดโบนัส | ✅ | ✅ | ❌ (ได้แต่ตัวเลข) |
| ADHD-friendly | กลาง | **สูง** | ต่ำ (frustration) |

- **คิวเลือก: B + C** · ขั้น = ปลดโบนัส, ตีบวก = ตัวเลขดิบ · ตีบวกใช้กติกาจาก POC เดิมของคิว (ขั้นต่ำง่าย, แตกแล้วซ่อมถูก, ขั้นสูงยาก + pity)
- ตัด A (รวมของซ้ำ) ทิ้ง เพราะต้องรื้อเซฟและออกแนวกาชา

### 3.5 ตีบวก (Refine) +1 ~ +10
- แต่ละ + = ค่าพลังทั้งชิ้น **+5%** (+10 = +50%) บวกกับ % ของขั้นแบบบวกตรง: `ตัวคูณ = 1 + ขั้น% + บวก%` (ขั้น 5 +10 = ×2.1)
- ตีได้ทุกชิ้น (รวมของร้าน) ยกเว้นของเริ่มต้นราคา 0 และช่อง "ว่าง"
- ตีในเมืองเท่านั้น (แท็บ ⚒️ ตีบวก ในโรงตีเหล็ก) ไม่มีแตกระหว่างต่อสู้

**โอกาสสำเร็จ** (ตัวเลขจาก POC ของคิว)

| จาก → ไป | +0→+4 | +4→5 | +5→6 | +6→7 | +7→8 | +8→9 | +9→10 |
|---|---|---|---|---|---|---|---|
| สำเร็จ | 100% | 70% | 55% | 40% | 30% | 20% | 12% |

- **Pity:** พลาดชิ้นเดิมติดกัน +10% ต่อครั้ง (สำเร็จแล้วรีเซ็ต) → +9→10 พลาดไม่เกิน ~9 ครั้งก็ได้แน่ โชว์ % จริงบนปุ่มเสมอ
- **พลาด = แตก (💔):** บวกไม่ลด ขั้นไม่ลด การ์ดไม่หาย ของไม่หาย · แค่ **ของชิ้นนั้นไม่ให้ค่าพลัง** จนกว่าจะซ่อม (การ์ดในนั้นก็ปิดด้วย กฎเดียวกับใส่ผิดอาชีพ) · ของแตกตีต่อไม่ได้ ต้องซ่อมก่อน
- ใส่ของแตกลงดันได้ แต่ขึ้นเตือนสีแดงก่อนเข้า

**ต้นทุนต่อครั้ง** (🧱 = วัตถุดิบธรรมดาของดันที่ของชิ้นนั้นมาจาก · 🔩 = เชื้อหลอม ดูข้อ 3.7)

| ตีไป | 🔩 เชื้อหลอม (ช่องเดียวกัน) | 🧱 | zeny |
|---|---|---|---|
| +1 ~ +4 | ของร้านพื้นฐานชิ้นไหนก็ได้ 1 | 2 | 50 × บวกเป้าหมาย |
| +5 ~ +7 | ของร้านราคา ≥ 200z 1 | 4 | 100 × บวกเป้าหมาย |
| +8 ~ +10 | ของร้านราคา ≥ 400z 1 | 6 + 💠1 | 150 × บวกเป้าหมาย |

### 3.5.1 ค่าสุ่มพิเศษที่ +5 / +7 / +10 (คิวสั่ง 17:00)
- ตีถึง **+5, +7, +10 ครั้งแรก** → ของชิ้นนั้นได้ **ค่าพิเศษสุ่ม 1 บรรทัด** (รวมสูงสุด 3 บรรทัด/ชิ้น) ค่าติดตัวของถาวร
- บรรทัดที่ได้จาก +5 = ระดับเล็ก · +7 = กลาง · +10 = ใหญ่ (ตัวเลขตามตารางล่าง)
- **10% เป็นบรรทัดทอง ✨** ค่า ×1.5 (ลุ้นเล็กๆ ไม่ต้องเสียอะไรเพิ่ม)
- ของแตก: บรรทัดยังอยู่ แค่ปิดไปพร้อมของจนกว่าจะซ่อม · ตีพลาดไม่ทำให้บรรทัดหาย
- ค่าซ้ำชนิดเดียวกันได้ (ข้ามบรรทัด/ข้ามชิ้น) แต่ cap เดิมยังทำงาน (ดูดเลือด 40%, คริ ฯลฯ)

**กองค่าที่สุ่มได้** (อิงแผงสถานะในเกม · ใช้ Stats ที่มีอยู่แล้วทั้งหมด)

| ค่า | +5 | +7 | +10 |
|---|---|---|---|
| ค่าสถานะหลัก 1 ตัว (STR/VIT/WIS/DEX/INT/LUK/AGI) | +1 | +2 | +3 |
| HP สูงสุด % (`maxHpPct`) | +2% | +3% | +5% |
| P.ATK % (`atkPct`) / M.ATK % (`matkPct`) | +2% | +3% | +5% |
| ดาเมจสกิลกายภาพ (`pskill`) | +2% | +4% | +6% |
| P.DEF (`def`) | +2 | +3 | +5 |
| M.DEF (`mdef`) / ต้านทาน (`tenacity`) | +1% | +2% | +3% |
| Hit / Flee | +3 | +5 | +8 |
| คริ (`crit`) / คริเวท (`spellCrit`) | +1% | +2% | +3% |
| ดาเมจคริ (`critMul`) | +5% | +10% | +15% |
| สวนกลับ / คอมโบ | +2% | +3% | +5% |
| ฟื้น HP/เทิร์น (`regen`) | +0.2% | +0.3% | +0.5% |
| ฮีลแรง (`healAmp`) | +2% | +4% | +6% |
| ดูดเลือด (`lifesteal`) | +1% | +2% | +3% |
| Max Mana / ฟื้น Mana | +5 / +0.5 | +8 / +1 | +12 / +1.5 |

- **ไม่อยู่ในกอง:** หลบโชคดี, ดรอปหายาก, พรตำนาน, อีเวนต์ (ค่าดวง/เศรษฐกิจ ไม่อยากให้ฟาร์มพุ่ง) และ flag ต่างๆ
- **ถ่วงน้ำหนักตามช่อง:** อาวุธ = ค่าโจมตีออกบ่อย ×2 · เกราะ/หมวก/มือรอง = ค่าป้องกัน/ฟื้นฟู ×2 · เครื่องประดับ = เท่ากันหมด
- **ถ่วงตามอาชีพที่ใส่ตอนตี:** ค่าที่อาชีพนั้นไม่ใช้เลย (เช่น M.ATK กับนักดาบ, ฮีลแรงกับนักธนู) น้ำหนัก ×0.25 → ไม่ถึงกับห้าม แต่ไม่ค่อยเจอขยะ

**สุ่มใหม่ = Gacha Option (v84, คิวสั่ง 2026-11-06 เพราะ zeny เริ่มเฟ้อ)** — แทนระบบเดิมที่สุ่มทีละบรรทัดแล้วเลือกเก็บอันเก่าได้
- กดสุ่มทีเดียว **เปลี่ยนทุกบรรทัดที่ไม่ล็อกพร้อมกัน** และ **ค่าเก่าหายทันที** (ไม่มีให้เลือกเก็บอันเก่าแล้ว)
- 💰 zeny = ราคาของทุกบรรทัดที่มีรวมกัน (+5 = 200 · +7 = 400 · +10 = 800 → ครบ 3 บรรทัด 1,400z) x **(1 + 10% ต่อครั้งที่สุ่มชิ้นนี้ไปแล้ว, สูงสุด x3)**
- 🧱 วัตถุดิบ = เท่ากับบรรทัดใหญ่สุดของชิ้นนั้น (🧱4 / 🧱6+💠1 / 🧱8+💠2)
- 🔒 **ล็อกบรรทัดได้ด้วยเพชรเท่านั้น** จ่ายต่อการสุ่ม 1 ครั้ง: ล็อกที่ 1 = 💎10 · ล็อกที่ 2 = 💎30 (รวม 40) · ห้ามล็อกครบทุกบรรทัด
- จำนวนครั้งที่สุ่มนับแยกแต่ละชิ้น (`rerollCount`) และล้างเมื่อขายหรือย้ายของชิ้นนั้นไปเป็นเชื้อหลอม
- โค้ด: `REFINE.reroll*` / `lockGems` ใน `craft.ts` · `reroll()` / `rerollCost()` ใน `refine.ts` · เทส `tests/option-gacha.test.ts`

### 3.7 ของร้านพื้นฐาน = เชื้อหลอม (🔩)
- ของร้านที่ **ไม่ล็อกอาชีพและไม่มี `req`** (ดาบสั้น 80z, มีดคู่, ค้อนไม้โอ๊ก, ดาบยาว, คทาฝึกหัด, เสื้อหนัง, เสื้อคลุมนักเวท, เกราะโซ่, เครื่องประดับร้าน 150–480z + หมวก/มือรองพื้นฐานใหม่) ใช้เป็นเชื้อหลอมได้
- ใช้ได้ 3 ที่: **ตีบวก** (ข้อ 3.5), **ซ่อม** (ข้อ 3.6), และ **สูตร Craft บางสูตร** (เช่น โล่ขนเงาจันทร์ = บัคเลอร์ 1 + 🧱8 + 💠2) แบบ RO ที่เอาของธรรมดามาต่อยอด
- เซฟเก็บของแบบ 1 ชิ้นต่อไอดี เลยแยกกองเชื้อหลอมเป็นจำนวน: ร้านมีปุ่ม **"ซื้อเป็นเชื้อหลอม"** (ราคาเท่าเดิม) → เข้า `fodder[itemId] = n`
- ของพื้นฐานที่มีในกระเป๋าแต่ไม่ได้ใส่ ย้ายเข้ากองเชื้อหลอมได้ (ปุ่ม "ใช้เป็นเชื้อ") · ชิ้นที่ใส่อยู่หรือมีการ์ดเสียบ ใช้ไม่ได้จนกว่าจะถอด
- ผลดี: zeny มีที่ใช้ตลอดเกม, ของร้านถูกๆ ไม่ไร้ค่าหลังเปลี่ยนอาชีพ
