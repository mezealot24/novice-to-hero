# Capybara Go! ออกแบบยังไง: สกิลตามด่าน · ไอเทม · การเอาตัวรอด

> ทีมค้นข้อมูล 3 สาย · 2026-11-03 · แหล่งข้อมูลเป็นวิกิ/ไกด์ของแฟนเกม (ไม่มีเอกสารทางการจาก Habby) ตัวเลขอาจเก่ากว่า patch ปัจจุบัน · (UV) = ยังยืนยันไม่ได้

## TL;DR (so what)

- **Capybara Go ไม่มีอาชีพ** บทบาทมาจาก "อาวุธ + สกิลที่สุ่มได้ในรอบ" เกมเลยไม่เคยเจอปัญหาตัวบางแบบเรา
- **สายดาเมจรอดได้เพราะ "ป้องกันที่โตตามดาเมจ"**: ดูดเลือด, โล่ที่สเกลตาม ATK, ฟื้นเมื่อสวนกลับ, ชุบชีวิต 1 ครั้ง · ไม่ใช่เพราะ HP เยอะ
- **บอสของเขาเป็นแค่ stat check** ไม่มีท่าเตือนให้อ่าน · ของเรามีท่าชาร์จ = **จุดที่เราเหนือกว่า** อย่าทิ้ง แค่ต้องให้ทุกอาชีพตอบโต้ได้
- **ไอเทมเป็นตัวกำหนด build** สกิลในรอบแค่ "เติมให้ครบ" · แต่เขาซ้อนระบบไว้ ~10 ระบบเพื่อขายของ ซึ่งเราไม่ต้องตาม
- สิ่งที่หนูแนะนำให้หยิบมา: ดูท้ายเอกสาร (ข้อ 4)

## 1. สกิลที่ให้เลือกตามด่าน

### จังหวะที่ได้เลือก
| แหล่ง | ได้อะไร | ราคา |
|---|---|---|
| เลเวลอัป | เลือก 1 ใน 3 | ฟรี |
| ภูต (Forest Sprite) | สกิล 1 อัน | เสีย 7% Max HP หรือ ATK |
| ฆ่า Elite | หีบทอง เลือก Mythic 1 ใน 3 | ต้องชนะ elite |
| ปีศาจ (Demon pact) | Legendary สุ่ม 1 อัน | เสีย Max HP ถาวรในรอบ |
| เทวดา (Angel) | สกิล vs ฮีล หรือ สกิล vs สกิล | ฟรี |
| วงล้อก็อบลิน (บางด่าน) | สุ่มสกิล | หมุนแรกฟรี หมุนสองเสีย HP |
| Bulk pick (บางด่าน) | สกิลพื้นฐาน 5 อันรวด | หลังเคลียร์ 5 เวฟ |
| อัศวินมืด | แปลงร่าง (Werewolf / Wizard / Vampire / Orc) | มี trade-off |
| โชคใหญ่ (Large Fortune) | Immortal (หายากสุด) | ทางเดียวที่ได้ |

- อีเวนต์เสี่ยงดวงจะ **บอก % สำเร็จก่อนกด**
- ตายในด่าน = เริ่มบทใหม่ สกิลหายหมด
- ไม่พบหลักฐานว่ามีปุ่ม reroll ตอนเลเวลอัป (UV)

### โครงสร้าง pool สกิล
- **ความหายาก 4 ขั้น**: Common → Legendary → Mythic → Immortal
- **Tag**: Basic, Skill, Rage, Counter + ธาตุ (กายภาพ/ไฟ/น้ำแข็ง/สายฟ้า/พิษ) + ชนิดอาวุธ (มีด/ดาบปราณ/หอก)
- **build หลัก 3 แบบ**: ตีปกติ (คริ/คอมโบ) · Rage · Round/Counter
- **ได้ซ้ำ = อัปเลเวล** Lv1–5 แล้วเป็น "+" เช่น Pig Smash +25% → +35% → (+) +50%
- **Evolution**: บางสกิลวิวัฒน์ เช่น Dodge → Drunken Fist · ขั้นหายากไม่วิวัฒน์
- **Transformer**: สกิลที่เปลี่ยนการทำงานของสกิลอื่น เช่น Smelly Dagger ทำให้มีดระเบิด
- **Prerequisite**: Frostbite โผล่เฉพาะเมื่อมี Icy Spikes หรือ Frozen Touch แล้ว → pool แคบลงตาม build
- **เลือกได้ทางเดียว**: สกิล Stance ล็อกกันเอง
- **cap ต่อกลไก ไม่ใช่ cap จำนวนสกิล**: ลดดาเมจ 75%, ไฟ 10 stack (Pyromancer ปลดเป็น 999), Golden Egg +5% ATK/DEF ต่อการต่อสู้ สูงสุด 10 ครั้ง

### อะไรเปลี่ยน pool
- บางบทมีอีเวนต์เฉพาะ (วงล้อ, bulk pick) · Hard mode ตัวเลขต่างจาก Story
- Spec Tree (ระบบถาวร) ปลดสกิลแล้ว pool เจือจาง ไกด์เลยแนะนำ "อย่าปลด"
- อาวุธเปลี่ยนสกิล: Ailoren แปลง Sword Chi ทั้งหมดเป็น 4 hit · สกิล Rage ต้องมีอาวุธ · อัญมณีอาวุธ "เลือกสกิล 1 อันตอนเข้าด่าน"

## 2. บาลานซ์สายไอเทม

### อุปกรณ์
- **6 ช่อง**: อาวุธ 1, เกราะ 1, แหวน 2, เครื่องประดับ 2
- **ขั้น**: Common → Superior → Rare → Epic(+1,+2) → Legendary(+1..+3) → Mythic(+1..+4) · ขั้นต้นรวม 3→1
- **ความหายากสำคัญกว่าเลเวล**: stat พื้นฐานแบนและน้อย (อาวุธ ATK +20/30/40/50) พลังจริงอยู่ที่ "โบนัสตอนขึ้นขั้น" ที่ Epic/Legendary
- **ของเกรด S**: มีโบนัสรวม เช่น S-Epic อาวุธ +25% ATK ทั้งตัว
- **อัปเลเวลคืนของได้เต็ม 100%** = ฟีเจอร์ที่ผู้เล่นชมมากที่สุด · ขั้นความหายากลดได้แค่ภายในขั้นเดียวกัน

### ไอเทมกำหนด build
| อาวุธ | ทำให้เกิด build |
|---|---|
| Whisperer | คริ 35% → สายคริ/คอมโบ |
| Nomad Staff | สายดาเมจสกิล |
| Frostwind Horn | สายแช่แข็ง |
| Silverscale Plate | สายสวนกลับ (counter ซ้อน 4) |

- Hero/Brand เปลี่ยนเศรษฐกิจ stat แบบมี trade-off: Wizard (สายฟ้าแรง แต่เสีย Combo/Counter), Orc (คริขึ้น แต่ไม่มี Rage)
- **ระบบซ้อน ~10 ระบบ**: สัตว์เลี้ยง, พาหนะ, Artifact, Relic, Brand, Insignia, Inheritance, Collectible, Talent... ทุกอันบวก % ใส่ stat ชุดเดียวกัน (คริ/คอมโบ/สวน/ATK)
- Artifact บางตัว "ทะลุ stat" ศัตรู (ไม่สนคริ/ไม่สนสวน) กัน PvP โดนแก้ด้วย stat เดียว

### คำบ่นของผู้เล่น
- กลางเกมโอเค ปลายเกม "soft pay-to-win" PvP leaderboard เป็นของคนเติม
- คอขวด F2P = **ของซ้ำสำหรับรวม S-gear** · เก็บเพชร ~6 สัปดาห์ต่อ banner
- ไกด์เต็มไปด้วย "เก็บไว้ อย่าใช้" และ "อย่ารวม S-gear ถ้าไม่ชัวร์" (ของหายถาวร)

## 3. การต่อสู้และการเอาตัวรอด

- **ลำดับในรอบ**: ตีปกติต้นรอบ → Rage เต็มยิงสกิล (~2x) → เอฟเฟกต์ต่อรอบ → สวนกลับเมื่อโดนตี · คอมโบ = โอกาสตีซ้ำ
- **Final Damage Reduction** (cap 90%) คือ stat ป้องกันที่ดีที่สุด
- **ฟื้นตัว**: ดูดเลือด, Resilience (3% ฮีลหลังแอ็กชัน), Counter Soul (ฮีลตอนสวน ถ้า HP <50%), Super Life (ฮีลเต็ม)
- **โล่**: โล่ตีปกติ **สเกลตาม ATK** · โล่ Rage สเกลตาม Max HP · Wisp ตายแล้วให้โล่ 30%
- **ชุบชีวิต 1 ครั้ง** (Revival Cape) ใช้ได้ทุกบิลด์
- **บอส**: เป็น stat check + ต้านทาน control · **ไม่มีท่าเตือน/เฟสชัดเจน** (UV) · Yeti ตั้งใจลงโทษ build แช่แข็ง
- **วิธีชนะบอสของผู้เล่น**: Shrink Spell (ศัตรูดาเมจ -35%), Shock Discharge (ดูด Rage บอส = เลื่อนท่าใหญ่), Battle-Hardened (ลดดาเมจโตทุกรอบ สูงสุด 75%), War Veteran (+15% ATK ต่อรอบ)
- **ไกด์มือใหม่แนะนำเก็บสกิลป้องกันก่อนดาเมจเสมอ** แม้แต่สาย glass cannon ก็ต้องดันลดดาเมจให้ถึง cap
- ความยากโตแบบ exponential + มี "กำแพง DR" ต่อบท (บท 1–80 ต้องมี 75%)

## 4. เทียบกับ Novice to Hero: หยิบอะไรมาดี

### ✅ หยิบมา (MVP)
1. **ป้องกันที่โตตามดาเมจ ให้ตัวบาง** (เข้ากับตัวเลือก A ที่เสนอไว้ และเสริมให้แน่นขึ้น)
   - ธนู: คริแล้วได้ **โล่ = 15% ของดาเมจ** หรือดูดเลือดเล็กน้อย
   - เวท: ult ร่ายแล้วได้ **บาเรีย** ตาม M.ATK
   - ทำให้ Break (ตีขัดท่าชาร์จ) มีคู่หู: ตีแรง = ขัดบอส + ได้โล่
2. **ชุบชีวิต 1 ครั้งต่อรอบ** เป็นการ์ดหายาก หรืออีเวนต์ "ภูตหลงทาง" → ตาข่ายนิรภัยกลางๆ ทุกอาชีพ
3. **การ์ดจ่ายด้วย HP** (เหมือนปีศาจ/ภูต) ใส่ตารางอีเวนต์เรา: "เสีย Max HP 10% ได้การ์ดตำนาน" · เราทำโครงอีเวนต์ไว้แล้ว เพิ่มแค่ 1 entry
4. **การ์ดซ้ำ = อัปเลเวล** (Lv1–3 แล้ว "+") แทนการ์ดซ้อนเฉยๆ · ผู้เล่นรู้สึกว่าโตชัด
5. **Prerequisite card**: การ์ดไฟขั้นสูงโผล่เมื่อมีการ์ดไฟ 2 ใบแล้ว → pool แคบตาม build ช่วยคนสมาธิสั้นเลือกง่ายขึ้นด้วย
6. **บอก % ก่อนกดอีเวนต์เสี่ยง** (น้ำพุลึกลับของเรายังไม่บอก)

### ⚠️ ปรับใช้
- **อาวุธกำหนด build**: ให้อาวุธ 1 ชิ้นมี 1 effect ที่ผูกกับ tag การ์ด (เช่น ธนูไฟ: การ์ดไฟออกบ่อยขึ้น) · แต่ stat พื้นฐานแบนๆ เหมือนเขา
- **ตีบวกแบบ RO**: ล้มเหลวเสียแค่วัสดุ (ไม่แตก) + pity counter + ย้ายระดับตีบวกข้ามชิ้นได้ · เลียนแบบ "คืนของได้" ที่ผู้เล่นชอบ

### ❌ ไม่เอา
- ระบบซ้อน 10 ชั้น → เราใช้แค่ 3: อุปกรณ์ · ตีบวก · การ์ด/certificate
- รวมของซ้ำ (duplicate merge) → ต้นเหตุ grind และอยากเติมเงิน ขัดหลัก no-squeeze ของเรา
- บอสแบบ stat check ล้วน → ท่าชาร์จของเราคือจุดขายที่ทำให้ "การกด ult" มีความหมาย
