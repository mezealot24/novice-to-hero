คัดลอกมาตรงๆ ไม่ได้แก้เนื้อหาค่ะ

Claude Code จะโหลด skill เหล่านี้เองเมื่องานตรงกับหัวข้อ ไม่ต้องสั่งชื่อ skill

| Skill | ใช้กับงานแบบไหนในเกมนี้ |
|---|---|
| `phaser-core` | Scene lifecycle, loader, camera ของ Phaser (เกมนี้ใช้ Phaser 3.90 ห้ามอัปเป็น 4 ถ้าไม่ได้สั่ง) |
| `game-feel` | ความมันตอนตี: screen shake, hit-stop, tween, ตัวเลขดาเมจเด้ง |
| `save-systems` | ระบบเซฟ, version ของ save, migration ตอนเพิ่ม field ใหม่ |
| `game-ui-ux` | HUD, เมนู, scale หน้าจอมือถือ |
| `rpg` | stat, เลเวล, inventory, เควส, combat |
| `roguelike` | run, dungeon, loot, permadeath |
| `itch-publish` | ปล่อยเกมขึ้น itch.io |

อยากได้ skill เพิ่ม ดูรายการเต็มได้ที่ repo ต้นทางค่ะ
